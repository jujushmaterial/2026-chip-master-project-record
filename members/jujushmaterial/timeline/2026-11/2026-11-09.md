## 2. 활동 목표

저전압에서 실패하던 3D SDevice 계산을 정상 실행하고, 도핑을 2D 결과에 다시 맞추지 않은 상태에서 3D VBD와 마지막 상태의 전기장 분석용 데이터를 확보한다.

## 3. 수행한 작업

### 3.1 선행 문제와 조치

기존 ILS 기반 실행은 약 0.2025 V에서 반복 실패했다. ParDiSo 및 진단 출력을 적용한 0.3 V 진단 코드가 성공했다는 사용자 보고 후, 전체 sweep용 SDevice v1.1을 사용했다. 선행 실패/진단의 정확한 실행일은 이번 기록에서 임의 지정하지 않는다.

### 3.2 실제 서버 실행

SDE Candidate-B v2.6의 electrical mesh `n1_msh.tdr`를 사용했다. anode/substrate를 0 V로 두고 cathode 0→14→25 V 목표 sweep을 실행했다. 25 V 도달 전 ionization-integral 종료 조건이 충족되어 마지막 TDR을 저장했다.

### 3.3 사용 도구 및 검증

- 소프트웨어: Sentaurus Device T-2022.03, 사용자 Linux 서버.
- 사용 AI: Codex/ChatGPT; 목적: solver 실패 분석, 수정 코드 보조, 로그 검토와 기록 정리.
- 검증 방법: 사용자 제공 전체 `n2_des.log`의 종료 표식·마지막 적분값·출력 TDR·자원 사용 확인. 이번 기록 작성 중 새 서버 실행은 하지 않음.

## 5. 해석

계산 실패에서 벗어나 breakdown 근처까지 수렴한 3D baseline 데이터를 확보했다. 정상 종료가 2D와의 전기적 동등성, mesh convergence 또는 실제 avalanche 증폭 전류 검증을 뜻하지 않는다. AvalPostProcessing의 정적 해임을 유지한다.

## 6. 문제점 및 한계

- 15.6 V에 도달하기 전에 종료하여 기존 2D SCR 평가 전압과 일치하는 결과가 없다.
- solver 변경 후 성공한 사실은 확인되지만 기존 실패의 모든 원인이 한 가지였다고 단정할 수 없다.
- 3D 메시 수렴과 실제 SCR 주변 해상도 적절성은 미검증이다.
