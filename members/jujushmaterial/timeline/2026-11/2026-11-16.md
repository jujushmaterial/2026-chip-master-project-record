## 2. 활동 목표

현재 실행에 사용한 3D SDE, SDevice, SVisualPy를 하나의 baseline으로 정리하고 VBD/SCR 결과와 한계를 추적 가능하게 남긴다. 앞으로 3D 구조 테스트에 같은 SDevice/SVisualPy 코드를 사용한다는 결정을 명시한다.

### 3.3 실제 데이터와 수치 검증

사용자 DOE 화면을 보관하고 로컬 중심선 CSV에서 SCR 중심·폭·접합을 재계산했다. 원본 도핑·전계 CSV는 공개 업로드에서 제외하고 재계산 요약과 원본 해시만 기록했다. VBD 정확한 수치는 DOE 근거, 로그 반올림값 계산은 보조 확인으로 분리했다. 부피는 사용자 화면 근거이며 원본 TDR 없이 독립적으로 재적분했다고 주장하지 않는다.

## 4. 확인된 결과

| 지표 | 값 |
|---|---:|
| VBD | 14.9128079157 V |
| 2D 대비 ΔVBD | −0.885190138673 V |
| SCR 평가 전압 | 14.9204276161 V |
| SCR 중심 | 150.684809982 nm |
| SCR 폭 | 305.471404049 nm |
| SCR 부피 | 126.117920651 µm³ |

SCR 중심/폭은 마지막 상태, STI 바닥 원점, 전계 임계값 1e5 V/cm 기준이다. 접합 깊이는 약 164.24 nm로 중심값과 다르다. 15.6 V SCR은 없다.

## 5. 해석

SDE v2.6 → SDevice v1.1 → SVisualPy v1.3의 실행 가능한 기준 조합을 확보했다. 2D의 SCR 중심 180.20 nm는 15.6 V에서 산출된 값이므로 현재 3D와의 약 −29.52 nm 차이는 동일 전압 비교 결과가 아니다. 도핑을 즉시 재보정하지 않고 비교 조건 및 메시를 먼저 검증한다.

## 6. 문제점 및 한계

- 3D 전용 SCR mesh window 밖에 접합 및 하단 경계가 있어 국부 수렴 검증이 필요하다.
- v1.3 서버 전체 로그와 원본 3D TDR/PLT는 이번 기록에 포함되지 않는다. 잘린 DOE 화면의 숨겨진 플래그는 추정하지 않는다.
- 과거 로컬 검사 39개 통과는 native Sentaurus 실행 검증을 대신하지 않는다.
- 코드 주석에 남은 배포 당시 미검증/15.6 V 문구는 원본 보존을 위해 유지하고 README에서 현재 의미를 정정한다.

## 7. 주요 결정 사항

**앞으로 3D 구조 테스트 시 SDevice v1.1 ParDiSo와 SVisualPy v1.3 VBD/SCR DOE를 공통 기준 코드로 사용한다.**

SDE v2.6은 reference로 보존하고 구조/메시 후보는 별도 버전으로 관리한다. 도핑·물리모델·VBD 정의·SCR threshold를 결과에 맞춰 변경하지 않는다. 구조 호환성 및 공통 바이어스 비교 원칙은 [공통 코드 사용 결정](../../assets/tcad/spad-baseline-3d/ELECTRICAL_TEST_POLICY_2026-11-16.md)에 따른다.
