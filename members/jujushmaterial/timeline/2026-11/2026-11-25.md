# 2026-11-25 연구 결정 · 동심형 STI의 3D 광생성 평가와 개인 논문 구성

주상현 · 개인 연구 · 2026-11-25 KST  
오늘 확정한 사항은 원고의 연구 질문, 비교 기준, 서술 순서다. 아래 순서는 독자가 평가 설계를 따라가는 순서이며, 시뮬레이션 수행일은 각 실행 기록을 따른다.

## 연구 질문과 원고 범위

940 nm 수직 입사에서 상부 STI를 동심형으로 배치하면, 기존 3D SPAD의 SCR 중심을 포함하는 깊이 구간에 생성되는 전자–정공 쌍의 수가 어떻게 달라지는가? 반경 방향 주기 `RadialPitch`에 따른 증가와 감소를 모두 검토한다. 주상현과 유용성은 각자 독립 연구로 원고를 작성한다. 이 원고의 비교 소자는 자체 3D baseline이며, 최종 원고의 Gao reference는 제외한다.

## 본문 구성

| 순서 | 본문에서 답할 질문 | 제시할 자료 |

| 2. 대응하는 2D baseline | 같은 도핑과 대응 단면으로 구현한 2D 모델에서 전기·광학 지표가 어떻게 달라지는가? | 2D·3D의 VBD, SCR 중심·폭, 평가 전압을 병기하고 각 차원의 광학 적분 방법을 명시 |

| 4. 동심형 3D 검증 | 동일한 3D 기준 깊이 구간에서 어느 pitch의 광생성이 얼마나 변하는가? | 3D baseline과 17개 구조의 고정 구간 적분값·변화율, 각 구조에서 별도로 추출한 VBD·SCR 중심 및 평가 전압 |

## 방법과 확인된 기준값

| 항목 | 3D baseline | 2D baseline |
|---|---:|---:|
| VBD | 14.91281 V | 15.79800 V |
| SCR 중심 깊이, STI 바닥 기준 | 150.68481 nm | 180.20295 nm |
| SCR 폭 | 305.47140 nm | 341.36574 nm |
| SCR 추출 바이어스 | 14.92043 V, 마지막 수렴 상태 | 15.6 V |
| 광생성 적분 기준값 | baseline EMW 실행 완료, 고정 구간 적분값 검증 대기 | 기존 2D 후처리 코드의 기준값 6.03348761659 × 10²¹ cm⁻³ s⁻¹ µm² |

- **전기적 추출.** 3D VBD는 전자·정공 이온화 적분 중 작은 값이 1을 처음 상향 통과하는 전압을 선형 보간한다. 고정 측정선 (x, y) = (4.6875, 0) µm에서 주 접합을 둘러싼 |E| = 10⁵ V/cm 교차점 두 개의 중점으로 SCR 중심을 정한다. 깊이 d = −Z이며 STI 바닥에서 아래쪽이 양수다. 후보별 전기 표에는 실제 추출 바이어스를 함께 쓴다. 두 baseline의 SCR은 서로 다른 바이어스에서 얻었으므로 깊이 차이의 해석에 이 조건을 포함한다.
- **3D 광학 주지표.** G(x,y,z)는 국소 광생성률 [cm⁻³ s⁻¹]이다. 중심면 Z = −0.15068481 µm의 그림은 공간 분포를 보여준다. 정량 지표 G_int [s⁻¹]는 3D baseline의 SCR 경계로 깊이를 고정한 영역에서 실리콘의 G를 부피 적분한 값이다. 현행 코드의 영역은 r ≤ 12.5 µm, −0.303420512 ≤ Z ≤ +0.002050892 µm이고 DOE 이름은 `G_SCRslab_s`다. 좌표 부피가 µm³이므로 적분에 10⁻¹²를 곱한다. 이 영역은 기준 측정선의 두 경계를 옆으로 확장한 원통형 구간이다. 각 후보에서 계산한 실제 SCR 중심은 별도 열에 기록한다.
- **광학 비교 조건.** 3D baseline과 17개 후보에 같은 입사 조건(940 nm, 1 W/cm², 수직 입사, 동일 선편광), 반복 셀, 적분 영역을 적용한다. 후보별 G_int를 검증된 3D baseline G_int로 나누어 비와 변화율을 산출한다. 작은 차이는 에너지 수지와 메시를 바꿨을 때의 변동까지 확인해 해석한다.
- **2D 선별 기준.** 2D 코드의 `G180_Avg`는 중심 깊이에서 가로 측정선을 평균한 값이고, `Gain_Ref`는 2D SCR 깊이 구간의 면적 적분을 2D baseline 값으로 나눈 값이다. 선정표의 `gain_2D`를 인용할 때 이 정의를 사용한다. 차원 간 경향은 각자의 baseline으로 정규화해 비교한다. 2D 원래 패턴에는 기존 STI와 겹치는 구간이 있으므로 3D 동심형으로 옮기며 달라진 형상도 방법에 기술한다.

## 17개 후보와 결과표

선정한 RadialPitch [µm]는 0.200, 0.215, 0.390, 0.650, 0.675, 0.685, 0.715, 0.730, 0.750, 0.760, 0.775, 0.810, 0.835, 0.880, 0.900, 0.960, 1.000이다. 선정표의 2D 적분비로는 10개가 baseline 초과, 7개가 미만이다. 두 집단을 함께 사용해 2D에서 보인 증감 방향이 3D에서도 유지되는지 확인한다. 3D 동심형은 중앙 Si/anode를 두고 반경 0.55–12.20 µm의 패턴 영역에서 설계 Si 면적비를 15%로 맞춘다.

최종 표에는 **3D baseline 1행과 pitch별 17행**을 둔다.

## 남은 작업과 결론 작성 기준

1. 3D baseline의 고정 구간 적분을 완료하고 광학 에너지 수지와 적분 검사를 확인한다.
2. 동심형 17개의 전기 해석에서 VBD, SCR 중심, 추출 바이어스를 기록하고 동일 좌표가 각 pitch의 Si와 STI 중 어느 구간 아래인지 함께 확인한다.
3. 17개 구조에서 EMW와 동일 구간 적분을 수행한다. 검증된 값으로 증가·감소·수치 변동 범위 안의 후보를 구분한 뒤 초록과 결론을 작성한다. 논문의 성능 주장은 이 조건에서 확인한 SCR 중심 부근의 광생성 변화 범위로 한정한다.
