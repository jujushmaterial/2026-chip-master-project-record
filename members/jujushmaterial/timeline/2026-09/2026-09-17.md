## 2. 활동 목표

frozen 28 nm FD-SOI surrogate Reference의 electrical/native-STI core를 유지하면서 A의 proposed concentric annular Si/STI optical pattern을 구성하고, intentional pattern의 global Si FF를 15%로 고정한 채 radial pitch만 변화시키는 2D EMW screening DOE를 구축한다. 또한 SWB에서 대량 split을 등록하고, 초기 SDE/TDR geometry가 의도대로 생성되는지 확인한다.

## 3. 수행한 작업

### 3.1 DOE variable 정의 정정

초기에는 native STI2/3/4 간격을 `STI_Gap`으로 sweep하는 sensitivity 구성을 검토했으나, 이는 A의 본 연구 독립변수와 다르므로 사용하지 않기로 했다.

A 본 DOE에서는:
- frozen native STI topology 유지
- proposed annular optical pattern만 추가
- `RadialPitch`만 독립변수
- `RingWidth`는 FF=15%를 유지하도록 종속 계산

으로 정정하였다.

### 3.2 annular FF solver 구현

2D duty cycle `RingWidth/Pitch`를 15%로 놓지 않고, 3D annular ring area를 사용해 pattern aperture 전체의 intentional Si area fraction이 15%가 되도록 SDE에서 ring width를 자동 계산하게 했다.

pattern aperture:

```text
r_inner = 0.55 um
r_outer = 12.20 um
```

native STI overlap은 RingWidth 보정에 사용하지 않고 별도 geometry diagnostic으로 계산한다.

### 3.3 코드 구성

사용 파일:

```text
CMP_SPAD_A_Annular2D_FF15_RadialPitch_SDE_v1.1.txt
CMP_SPAD_A_Annular2D_FF15_SNMesh_v1.0.txt
CMP_SPAD_A_Annular2D_FF15_940nm_EMW_v1.0.txt
CMP_SPAD_A_Annular2D_FF15_SVisualPy_DOE_v1.1.txt
```

SVisualPy에서 SCR-integrated OpticalGeneration, Reference gain, 180 nm alignment, SCR hotspot 및 FF diagnostic을 SWB DOE variable로 출력하도록 구성하였다.

### 3.4 radial-pitch DOE 범위 구성

1차 broad screening:

```text
RadialPitch = 0.200 ~ 1.000 um
step        = 0.005 um
0.270 um    = excluded
Total       = 160 cases
```

0.270 um는 finite aperture 끝에서 현재 5 nm minimum mesh보다 훨씬 작은 약 0.283 nm terminal STI fragment가 생기는 numerical guard case라 제외했다.

기존 SWB에 0.200 um case가 존재하여 신규 CSV는 0.205~1.000 um에서 0.270 um를 제외한 159개 case로 작성했다.

### 3.5 SWB import troubleshooting

SWB Import Experiments의 header parser에서 `can't read "parameters": no such variable` 오류가 발생했다. headerless CSV를 사용하고 `Header=None`, `Skip First=0`, column mapping 0~3을 직접 지정하는 방식으로 우회했다.

### 3.6 초기 TDR geometry 확인

0.200~0.215 um 초기 case의 TDR을 확인했다. 전체 device 폭으로 보면 intentional Si/STI stripe가 매우 조밀하게 겹쳐 보이나 확대 시 개별 feature가 분리되어 있음을 확인했다.

작은 pitch에서는 pattern aperture 한쪽에 수십 개 period가 들어가고 x=0 mirror로 full diametric section이 생성되므로 Reference보다 훨씬 많은 STI/Si stripe가 보이는 것이 설계상 예상된다.

## 4. 확인된 결과

- `RadialPitch`가 A의 유일한 geometry DOE 독립변수로 정리됨
- intentional annular pattern의 `PatternFF_3D=0.15`를 유지하는 area-based width solver 구현
- native STI1~5 geometry는 frozen 상태 유지
- 0.200~1.000 um, 기본 5 nm step, 0.270 um 제외 총 160-case DOE 구성
- SWB import용 159-case CSV 생성 및 값 검증
- 초기 0.200~0.215 um SDE/TDR geometry에서 조밀한 patterned structure 생성 확인
- Reference의 공식 pattern FF는 N/A이며, 동일 A-comparison aperture에서 surrogate geometric Si-area fraction을 계산하면 약 91.6183%임. 이 값은 Gao FF=15%와 동일 개념의 공식 Reference FF로 사용하지 않음.

## 5. 해석

현재 단계는 geometry/DOE setup validation 단계이다. 작은 pitch에서 많은 STI가 보이는 것 자체는 오류 근거가 아니며, pitch가 증가하면 radial period 수가 감소해야 한다. 최종 optical 성능 판단은 TDR 모양이 아니라 동일 EMW 조건에서 `G_SCR_Int`, `Gain_Ref` 등 정량 metric을 사용해야 한다.

2D EMW는 exact 3D annular optical solution이 아니므로 2D optimum을 최종 결론으로 사용하지 않는다.

## 6. 문제점 및 한계

- 160 cases 전체 EMW 결과가 아직 정리되지 않음
- 2D extruded optics와 실제 3D concentric-annular optics 사이 차이가 존재
- pattern aperture 0.55~12.20 um는 surrogate design definition
- very-small feature case는 current 5 nm mesh에서 numerical sensitivity 가능
- native-STI overlap 후 `FinalSiFF`는 pitch별로 달라질 수 있으나 primary comparison constraint는 intentional pattern FF=15%임

## 7. 주요 결정 사항

- native-STI spacing sweep은 A 본 DOE로 사용하지 않음
- A 본 1차 screening variable은 `RadialPitch` 하나로 고정
- intentional annular pattern global FF=15% 고정
- RingWidth는 dependent variable
- native STI overlap은 diagnostic으로만 기록
- 2D screening 후 약 5개 대표 후보를 3D로 가져감
