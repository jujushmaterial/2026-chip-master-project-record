## 2. 활동 목표

160-case 2D EMW radial-pitch screening 결과를 바탕으로 실제 3D concentric annular SDE/EMW로 가져갈 후보군을 확정한다. 단순히 2D 상위 성능 case만 3D로 재검증하지 않고, 2D에서 성능이 가장 낮았던 low-pitch case도 negative control로 포함하여 2D screening에서 나타난 pitch-regime 경향이 3D에서도 유지되는지 검증할 수 있도록 구성한다.

## 3. 수행한 작업

### 3.1 2D 최저 성능 구간 재확인

160-case 결과에서 `Gain_Ref` 기준 최저값을 다시 정렬하였다.

| 순위 | RadialPitch | Gain_Ref | Reference 대비 | G_SCR_Int |
|---:|---:|---:|---:|---:|
| Worst #1 | 200 nm | 0.870671 | -12.93% | 5.25318e+21 |
| Worst #2 | 205 nm | 0.871351 | -12.86% | 5.25728e+21 |
| Worst #3 | 215 nm | 0.871730 | -12.83% | 5.25957e+21 |

200 / 205 / 215 nm는 모두 같은 low-pitch regime에 매우 가깝기 때문에 세 점을 모두 3D로 가져가는 것보다, 대표성이 있는 두 점을 negative control로 선택하는 것이 계산량과 검증 목적의 균형이 좋다고 판단하였다.

### 3.2 기존 preliminary high-performance 후보 재확인

기존 2D screening에서 3D 검증 후보로 잡았던 case는 다음과 같다.

- 750 nm: positive-gain control
- 775 nm: 첫 번째 strong integrated local peak
- 835 nm: `Gmax_SCR` global maximum
- 900 nm: `G_SCR_Int / Gain_Ref` global optimum
- 1000 nm: upper-bound control

### 3.3 최종 annular 3D validation set 결정

negative control 2개를 추가하여 다음 7개 annular case를 3D validation set으로 확정하였다.

```text
200 / 215 / 750 / 775 / 835 / 900 / 1000 nm
```

역할은 다음과 같다.

| RadialPitch | 3D 검증에서의 역할 |
|---:|---|
| 200 nm | 2D global-worst negative control |
| 215 nm | low-pitch negative control / bottom-3 representative |
| 750 nm | Reference 초과 high-pitch regime control |
| 775 nm | first strong integrated local peak |
| 835 nm | hotspot maximum candidate |
| 900 nm | primary integrated optimum candidate |
| 1000 nm | upper-bound response control |

## 4. 확인된 결과

- 2D worst case는 200 nm이며 `Gain_Ref=0.870671`이다.
- 205 nm와 215 nm도 유사한 low-pitch 저성능 구간에 있으므로 3개 모두를 포함할 필요는 낮다.
- 3D annular validation set은 **200 / 215 / 750 / 775 / 835 / 900 / 1000 nm**의 7개 case로 결정하였다.
- 최종 3D 비교에는 이 7개 annular case 외에 **Reference 3D**와 **Gao Square 480 nm / FF15% 3D**를 별도 benchmark로 포함한다.
- 따라서 현재 계획 기준 최종 3D optical comparison 구조 수는 총 9개이다.

## 5. 해석

3D 검증의 목적은 2D에서 얻은 정확한 숫자나 순위가 그대로 재현되는지만 보는 것이 아니다. 2D screening이 설계 후보를 선별하는 데 유효했는지 검증하기 위해 다음과 같은 **regime/rank consistency**를 우선 확인한다.

예시 기대 경향:

```text
low-pitch negative controls
    <
positive-gain / local-peak candidates
    <
high-performance candidates
```

즉 200 / 215 nm와 같은 low-pitch case가 3D에서도 상대적으로 낮은 photogeneration을 보이고, 835 / 900 nm와 같은 high-performance 후보가 상대적으로 높은 성능을 유지한다면 2D screening의 선별 능력을 뒷받침할 수 있다.

반대로 3D에서 순위가 일부 변경되는 것은 허용한다. 최종 annular optimum은 3D EMW 결과를 기준으로 결정하며, 2D 결과를 exact 3D 성능으로 해석하지 않는다.

## 6. 문제점 및 한계

- 2D screening은 extruded geometry이므로 3D concentric annular 구조의 azimuthal field distribution을 직접 재현하지 않는다.
- finite aperture, native-STI overlap, `N_Radial` transition 효과가 2D response modulation에 함께 포함되어 있다.
- 3D 계산량이 증가하므로 7개 annular case는 대표성과 계산 비용을 고려한 선택이다.
- 3D에서 2D와 동일한 정확한 peak 위치 또는 순위가 유지된다고 사전에 가정하지 않는다.

## 7. 주요 결정 사항

- **최종 annular 3D validation set: 200 / 215 / 750 / 775 / 835 / 900 / 1000 nm**
- 200 nm와 215 nm를 negative control로 포함한다.
- 205 nm는 200 / 215 nm와 동일 low-pitch regime에서 정보 중복이 크므로 제외한다.
- 3D validation 평가는 절대 순위 일치보다 low-/mid-/high-pitch regime의 상대 경향 유지 여부를 우선 본다.
- 최종 3D benchmark는 Reference / Gao Square 480 nm FF15% / Annular 7 cases로 구성한다.
- final optical claim과 final annular design은 3D EMW 결과 후 확정한다.

## 12. 후속 결정 — Codex 논문 재분석 후 3D baseline 재검토

### 12.1 결정 배경

3D Reference를 실제로 구현하기 전에 기존 2D surrogate baseline을 기준으로 3D lateral geometry를 검토하였으나, 동일 연구계열 논문에서 다음 항목은 topology/역할은 확인되지만 exact mask coordinate가 공개되지 않은 것으로 재확인되었다.

- 2024 quasi-circular Reference의 exact XY polygon vertex
- PW / DNW exact top-view mask
- STI2 / STI3 / STI4의 exact top-view segment coordinate
- peripheral STI5의 exact perimeter 및 overlap 치수
- anode / cathode / substrate exact mask coordinate
- native minimum STI design-rule 절대값

따라서 기존 요약과 기억만을 바탕으로 3D SDE 코드를 바로 작성하면 비공개 geometry를 임의로 채우는 문제가 생길 수 있다고 판단하였다.

### 12.5 기존 2D frozen baseline의 지위

Codex 재분석 중에도 현재 2D baseline은 임의로 수정하지 않는다.

현재 주요 electrical fingerprint:

```text
VBD              = 15.7979980544 V
SCR p-side       = 0.00952007710343 µm
SCR n-side       = 0.350885814092 µm
SCR center proxy = 0.180202945597 µm
SCR width        = 0.341365736988 µm

DNW analytic PeakVal = 3.15e17 cm^-3
PW analytic PeakVal  = 5.95e17 cm^-3
```

현재 stack / representative surrogate cross-section:

```text
Upper Si  = 0.007 µm
BOX       = 0.025 µm
STI depth = 0.300 µm

STI1 = 0.700–1.300 µm
STI2 = 2.975–3.275 µm
STI3 = 6.100–6.400 µm
STI4 = 9.225–9.525 µm
STI5 = 12.200–12.800 µm
```

주의:
- 위 STI 좌표는 existing 2D surrogate representative cut의 값이다.
- 3D ring radius가 아니다.
- exact foundry dimension이라고 주장하지 않는다.

### 12.6 Codex 분석 후 3D Reference 재검토

Codex 문헌 분석이 끝난 후 3D Reference를 다음 정의로 다시 검토한다.

> **기존 frozen 2D surrogate baseline의 vertical/electrical fingerprint를 유지하면서, 재분석된 동일 연구계열 문헌이 지원하는 non-axisymmetric pseudo/quasi-circular lateral topology를 반영한 3D literature-constrained surrogate Reference**

3D Reference는 단순 cylindrical revolution으로 만들지 않는다.

특히 다음을 금지한다.

- 2D half-cell을 단순 회전하여 exact circular device로 생성
- STI2/3/4/5를 concentric ring으로 변환
- STI 위치를 자유롭게 sweep하여 VBD≈15.8 V가 되는 구조를 역으로 찾기
- geometry와 doping을 동시에 자유 fit
- 논문 figure pixel length를 실제 nm 값으로 선언
- 3D 결과가 다르다는 이유만으로 PW/DNW doping을 즉시 재-fit

### 12.7 surrogate XY mask가 계속 필요한 경우

Codex 재분석 후에도 exact top-view geometry가 공개되지 않은 경우에만 surrogate XY mask를 정의한다.

이 경우:
- 논문 topology 고정
- 25 µm-class pseudo/quasi-circular footprint 유지
- 기존 2D representative cut 보존
- 필요 시 2–3개 plausible XY mask 후보 정의
- 새 좌표는 [그림 판독 추정] 또는 [surrogate assumption]으로 표시

TCAD split은:

> “어떤 임의 geometry가 VBD=15.8 V를 만드는가?”

를 찾는 용도가 아니라,

> “문헌과 기존 2D baseline을 모두 만족하는 plausible 3D geometry 중 어느 realization이 electrical fingerprint를 가장 안정적으로 보존하는가?”

를 확인하는 용도로만 사용한다.

### 12.9 Gao benchmark validation gate

Gao Square 3D를 만든 뒤 바로 Annular로 넘어가지 않는다.

먼저 Reference와 Gao Square의 3D EMW 결과를 비교하고, Codex가 다시 정리한 2021/2024 논문의 compatible simulation result와 비교한다.

중요:
- 우리 `SCR-integrated photogeneration gain`과 measured PDP gain을 동일 quantity로 취급하지 않는다.
- 논문 direct optical simulation quantity가 있으면 우선 비교한다.
- simulated PDP는 ATP / quasi-neutral collection 등 methodology 차이를 함께 본다.
- measured PDP gain은 secondary benchmark로 사용한다.

차이가 크면 다음을 확인한다.

- geometry simplification
- native STI representation
- BEOL treatment
- optical constants
- incidence condition
- lateral boundary
- domain size
- mesh
- SCR/active-region integration definition
- ATP coupling
- quasi-neutral carrier collection
- polarization
- finite aperture

원인 분석과 기록이 끝난 후 Annular 7 cases로 진행한다.
