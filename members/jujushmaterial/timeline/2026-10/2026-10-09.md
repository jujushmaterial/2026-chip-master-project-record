- 작성자: `jujushmaterial` (주상현, Member A)
- 실제 관련 활동: 2026-10-08~2026-10-09. 개별 초기 버전 개발의 정확한 일자는 이 기록에서 추정하지 않음.
- 3D SDE 코드 채택일: **2026-10-09**
- 활동 제목: Candidate-B 3D surrogate SPAD — frozen Gaussian doping, Dual MSH 및 radial coarse-bulk mesh 완성
- 활동 구분: Design, Development, Simulation, Troubleshooting, Review, Documentation
- 진행 상태: **Completed (SDE 코드 확정)** / **Needs Review (3D electrical/mesh convergence)**

## 2. 활동 목표

28 nm FD-SOI SPAD의 문헌 제약 기반 quasi-circular surrogate Reference를 3D Sentaurus SDE에서 구현하고, frozen 2D surrogate의 PW/DNW 도핑 계열을 최대한 보존한다. 실제 도핑 field를 포함한 electrical/physical 3D MSH를 모두 생성하고, 외곽 Bulk의 불필요한 mesh를 줄이면서 SCR, STI 및 PEB 주변에 국소적으로 해상도를 배분한다. 구조와 mesh 방식이 사용자 의도에 부합하면 코드를 **향후 3D Reference SDE의 기준**으로 고정한다.

이는 실제 Gao/ST 제조 레시피 복원이 아니며, 3D SDevice 전기 특성이 2D와 동일하다고 인증하는 절차도 아니다.

## 4. 확정 코드 및 물리 구조

### 4.1 확정 산출물

- **코드:** [v2.6 SDE 전체 TXT](../../assets/tcad/spad-baseline-3d/CMP_SPAD_3D_CandidateB_v2.6_RadialCoarseBulk_UpperSiZFixed_DualMSH.txt)
- **상세 기록:** [3D baseline README](../../assets/tcad/spad-baseline-3d/README.md)
- **원문 보존:** 1,012줄, 44,815 bytes, Git blob SHA `da5e8d0dc2534cd80d0ba0b2bcb811c990b00a6b`. 코드 원본 그대로 보존; header/footer의 legacy `v2.4` 표기는 실행 코드를 변경하지 않기 위해 그대로 둠.

### 4.2 도핑·STI·contact

- 28 nm FD-SOI, 약 25 µm-class quasi-circular SPAD [동일 연구계열 constraint].
- Bulk Silicon radius 24 µm, z=-10~+0.300 µm; upper Si 7 nm, BOX 25 nm. STI1–4 및 STI5/6/7 유지.
- 17×17 Cartesian-segment 중 유효 cell 257개, Active-STI Oxide 188개, UpperSi 해당 cell 69개. Peripheral STI5는 staircase로 구성.
- Frozen 2D analytic 설정으로부터 PW Boron `PeakVal=5.95e17 cm^-3`, DNW Phosphorus `PeakVal=3.15e17 cm^-3` 유지. 3D에는 lateral `hypot(x,y)` 기반 Gaussian `General` profile 사용.
- Geometry, STI dimensions, contact positions, 절대 doping process recipe는 [surrogate assumption] 및 2D [역산/fit]으로 구분. 비공개 foundry mask와 동일하다고 주장하지 않음.
- Reference STI2/3/4를 제거하지 않으며 reference optical FF·periodic pitch는 정의하지 않는다.

### 4.3 Dual MSH

1. `n@node@_msh.tdr`: frozen 2D convention에 따른 **UpperSi=Oxide electrical surrogate**, Bulk doping 포함.
2. `n@node@_physical_msh.tdr`: **UpperSi=Silicon physical stack**으로 복구 후 재생성, Bulk doping 포함.

`bnd.tdr`은 도핑 field를 포함한 3D solver MSH를 대신하지 않으므로 두 개를 순차 생성한다. 두 파일의 UpperSi 재료 차이가 3D 전기 특성에 미치는 영향은 별도 민감도 평가가 필요하다.

### 4.4 v2.6 mesh 확정 원칙

- `MeshScale=1.50`; Global XY max 10.5 µm / min 3.15 µm, 깊은 Bulk 매우 coarse.
- M2: 원통형 Bulk transition, DNW transition, 상부 doping gradient, 잠정 SCR window.
- M3: BOX 및 anode 국소 refinement. **UpperSi 7 nm 수직 Zmax=3.5 nm, Zmin=2.5 nm 고정**.
- M4: 실제 Cartesian STI1–4 주변에서만 interface refinement.
- M5: STI5/PEB(r=11.9–15.8 µm), NW cathode(r=13.85–15.75 µm), STI6/7 outer pickup(r=16.75–19.65 µm) 등을 깊이 제한된 **annular mesh window**로 처리.
- 실체 STL/STI geometry는 원형으로 변경하지 않는다. 임시 cylinder/annulus body는 mesh용 Ref/Eval 추출 후 제거한다.
- 전역 `zCuts` 제거, `fitInterfaces=FALSE`, `skipSameMaterialInterfaces=TRUE`, `maxNeighborRatio=5`.

## 5. 확인된 결과

- v2.2 M1의 과거 로그에서 `Conformal? true`, 60,303 points, 320,170 elements를 확인했다. **v2.6 요소 수가 아니다.**
- v2.4 Stage5의 과거 로그에서 과도한 mesh 정점 증가와 계산 부담을 확인했다.
- v2.5 SVisual 이미지에서 외곽 Bulk가 계획보다 촘촘하고 하부에 가느다란 직선형 mesh가 반복되는 현상을 확인했다.
- 사용자 제공 **v2.6 3D 전체 및 단면 SVisual**을 검토하고, 외곽 Bulk coarse + SCR/STI radial local refinement가 연구 목적에 적절하다는 결정을 내렸다.
- 따라서 **v2.6을 공동 baseline의 3D SDE reference code로 확정**하였다. 전기적 성능이나 광학 gain 향상을 측정했다고 주장하지 않는다.

## 6. 문제점·한계

- 이번 기록에 v2.6 electrical 및 physical SMesh의 **최종 point/tetra count, minimum angle, non-Delaunay 품질 통계 로그**가 아직 포함되지 않았다. 정량 감소율을 산출하지 않는다.
- 기존 2D frozen electrical 기준: VBD `15.7979980544 V`, SCR center proxy `0.180202945597 µm`, SCR width `0.341365736988 µm`는 **2D 결과**이다. 3D에도 같게 나온다는 보장이 없다.
- Native 2D Gaussian 및 3D `General` radial Gaussian의 함수·mesh 보간·geometry 차이를 line cut으로 대조해야 한다.
- 3D reverse I–V, breakdown onset/위치, central/edge electric field, SCR, impact ionization, dark-generation, ATP, UpperSi 물질 민감도는 아직 미검증.
- Mesh-only 원형 window가 실제 curved tetra를 뜻하지 않는다. mesh convergence로 해상도 적절성을 별도 검증해야 한다.

## 12. 후속 결정 — Annular 3D 검증 후보 17개 확장 (2026-10-09)

### 12.1 배경 및 승인된 변경

2026-09-28 **160-case 2D EMW radial-pitch screening**에서 선별하여 2026-10-06 결정한 Annular 7개 검증 후보를 **전부 유지**하고, 사용자가 직접 체크한 peak/valley 및 완만한 구간을 확인할 **신규 10개**를 추가하기로 결정하였다.

- **기존 7개:** 200 / 215 / 750 / 775 / 835 / 900 / 1000 nm
- **신규 10개:** 390 / 650 / 675 / 685 / 715 / 730 / 760 / 810 / 880 / 960 nm
- **최종 Annular 17개 (오름차순):** **200 / 215 / 390 / 650 / 675 / 685 / 715 / 730 / 750 / 760 / 775 / 810 / 835 / 880 / 900 / 960 / 1000 nm**
- **전체 3D 비교:** Annular 17개 + Reference 3D + Gao Square 480 nm, FF15% 3D = **총 19개 구조**.

본 파일 상단의 원래 “Annular 7-case 후속 과제”와 “7-case 3D EMW 미완료 작업”은 **그 시점의 역사적 기록**으로 보존한다. **현재 실행 대상은 17-case**이며, 이전 7-case 계획의 범위만 확장되었다.

### 12.2 선정 목적과 평가 방향

- 200/215/390/1000 nm: 저·중·고 pitch regime 및 인접 지점의 **2D↔3D 추세 신뢰성** 점검.
- 650↔675, 685↔715, 730↔760, 775↔810, 835↔880, 900↔960 nm 주변: **국소 peak–valley contrast의 유지/약화/반전** 확인.
- 835 nm는 **2D Gmax_SCR 최대 후보**, 900 nm는 **2D G_SCR_Int 최대 후보**로 둘 다 유지.
- 개별 구간을 실제 3D에서 peak/valley로 재현했다고 주장하지 않는다. Ring 수 변화(N_Radial), native STI overlap, FinalSiFF, finite aperture, mesh/boundary 효과를 함께 점검한다.

### 12.3 고정 조건 및 연구상 주의

- 940 nm, optical material/source normalization 고정, intentional Si pattern FF=15%.
- radial pitch만 독립변수; ring width는 FF 유지용 종속변수. STI depth는 주 sweep이 아닌 고정 조건.
- 기존 **3D Reference Candidate-B v2.6 SDE 기준 코드**와 frozen PW/DNW electrical core는 변경하지 않는다.
- Reference native STI 유지. Reference에 intentional FF/pitch를 부여하지 않음.
- 모든 19개 구조에서 **SDE → SDevice → SVisualPy → electrical PASS → EMW** 적용.
- Reference 및 Gao Square benchmark 검증 후 annular 17개 optical validation 수행. 최종 성능 및 최적 pitch는 3D EMW 결과 후 확정.
- 신규 후보의 국소 극값 명칭은 2D screening에서 관찰한 **검증 대상 구간**이지 3D 실험 결과가 아님.
