## 3. 수행한 작업

### 3.1 SProcess 결과의 SMesh 연결 구조 재정리

#### 작업 배경

SProcess의 최종 `fps.tdr`에는 공정 결과와 doping profile이 포함되어 있지만, 이를 그대로 SDevice용 최종 mesh로 사용하는 대신 device simulation에 적합한 mesh와 profile mapping 단계가 필요하였다.

#### 수행 내용

SProcess 결과를 SDevice에 연결하기 위해 SMesh를 두 단계로 분리하였다.

1. SNMESH 1
   - SProcess `fps.tdr`의 geometry/boundary를 추출
   - `Mesh2bnd`를 사용하여 boundary TDR 생성

2. SNMESH 2
   - SNMESH 1의 boundary를 geometry input으로 사용
   - 해당 SProcess case의 `fps.tdr` doping profile을 SubMesh로 interpolation
   - SCR/junction/STI5/peripheral region을 중심으로 device mesh 생성
   - 최종 `msh.tdr`을 SDevice 입력으로 전달

Geometry가 변하지 않는 B process calibration에서는 Mesh2bnd 역할의 SNMESH 1 결과는 공통 geometry boundary로 사용할 수 있고, SProcess profile이 달라지는 경우 SNMESH 2에서 각 case의 profile을 다시 mapping하는 구조로 정리하였다.

### 3.2 SProcess–SDE coordinate mapping 정리

#### 수행 내용

SProcess와 기존 SDE/SVisual asset의 coordinate 기준이 다르기 때문에 공통 기준을 재정리하였다.

현재 SProcess raw coordinate에서:

- bulk Si surface: `0.000 µm`
- 공통 grating/Si interface anchor: `0.300 µm`

프로젝트 공통 optical/electrical depth는 다음과 같이 정리하였다.

`z_if = raw_y - 0.300 µm`

이에 따라 SVisualPy의 SCR extraction 좌표 기준도 SProcess/SMesh 결과에 맞게 수정하였다.

### 3.3 SDevice mesh dependency 문제 점검

#### 작업 배경

Workbench node 번호 기반 dependency를 사용하는 과정에서 SDevice가 의도한 최신 SMesh output이 아니라 다른 node의 mesh를 읽을 가능성이 확인되었다.

#### 수행 내용

- `@node|-1@`가 실제 upstream SMesh node를 의미하지 않을 수 있음을 확인하였다.
- node 번호 자체보다 현재 experiment의 upstream TDR을 전달하는 구조를 기준으로 dependency를 점검하였다.
- 이후 baseline calibration에서는 각 SProcess case → SNMESH profile mapping → SDevice가 동일 experiment branch로 연결되도록 관리하기로 하였다.

이 문제는 향후 multi-case calibration에서 서로 다른 process profile이 실제 SDevice input에 반영되는지 확인해야 하는 핵심 dependency issue로 기록하였다.

### 3.4 VBD/SCR calibration용 SDevice/SVisualPy 재구성

#### 수행 내용

기존 2026-08-27 diagnostic SDevice의 physics와 ionization-integral breakdown 정의는 유지하면서 SProcess/SMesh output을 사용할 수 있도록 calibration flow를 수정하였다.

또한 기존 SCR extraction이 15.6 V snapshot을 기준으로 하였으나, 현재 process candidate의 VBD가 15.6 V보다 낮을 경우 breakdown criterion에 의해 V156 snapshot이 생성되기 전에 SDevice가 종료되는 문제가 있었다.

따라서 diagnostic 목적으로 15.0 V snapshot인 `V150_des.tdr`을 읽는 SVisualPy variant를 구성하였다.

이 V150 결과는 최종 baseline과의 동일-bias 비교값이 아니라 process candidate의 SCR 이동 방향을 확인하기 위한 diagnostic metric으로 사용하였다.

### 3.5 95 keV PW trim seed의 첫 electrical validation

#### 수행 내용

현재 SProcess profile calibration seed인 95 keV PW trim 조건을 SMesh와 SDevice에 연결하여 첫 electrical validation을 수행하였다.

확인된 주요 결과:

- `VBD ≈ 15.025 V`
- V150 diagnostic SCR center ≈ `228.9 nm`
- V150 diagnostic SCR width ≈ `391.8 nm`
- avalanche peak depth ≈ `202.8 nm`
- center electric field ≈ `513.6 kV/cm`
- peripheral electric field ≈ `493.4 kV/cm`
- `Eperiph/Ecenter ≈ 0.961`

공통 electrical baseline의 목표 VBD 약 15.8 V 및 SCR 위치 약 180 nm와 비교할 때 현재 surrogate process seed는 추가 calibration이 필요한 상태임을 확인하였다.

### 3.6 80 keV PW trim diagnostic 시도 및 수렴 문제 확인

#### 수행 내용

SCR 위치 이동 방향을 확인하기 위해 PW Trim Energy를 80 keV로 낮춘 diagnostic run을 시도하였다.

해당 SDevice 계산에서는 breakdown 접근 과정에서 Newton convergence가 악화되었고, quasistationary step이 반복적으로 감소한 뒤 `Step-size less than MinStep` 조건으로 종료되는 failure가 발생하였다.

따라서 80 keV run은 최종 baseline candidate로 사용하지 않았으며, 공식 baseline calibration은 95 keV process seed를 기준으로 이어가기로 하였다.

이 결과를 PW Trim Energy의 물리적 최종 sensitivity로 단정하지 않고 solver/mesh convergence issue가 포함된 diagnostic 결과로만 기록한다.

### 3.7 Baseline calibration 방향 재정리

#### 수행 내용

현재 단계의 목적이 B 연구의 최종 성능 최적화가 아니라 공통 baseline을 재현하는 것임을 다시 명확히 하였다.

따라서 baseline process calibration에서는 다음 원칙을 사용하기로 하였다.

- 95 keV PW trim process seed를 calibration origin으로 사용
- doping profile이 SDE analytic profile과 완전히 동일할 필요는 없지만 문헌 제약상 plausible한 profile을 유지
- VBD와 SCR뿐 아니라 SCR width, electric field, avalanche position을 함께 확인
- PEB, dark current, ATP 개선 여부를 baseline 선정 기준으로 사용하지 않음
- baseline candidate 확정 후에만 B-track 본 DOE를 시작

## 5. 해석

2026-08-27-2에서는 SProcess profile calibration까지만 수행하고 SDevice electrical equivalence 검증은 미완료 상태였으나, 이번 작업에서 SProcess 결과를 SMesh를 통해 SDevice에 연결하고 실제 VBD/SCR/field metric을 추출하였다.

따라서 SProcess surrogate baseline 연구는 단순 profile 비교 단계에서 electrical calibration 단계로 진행하였다.

현재 95 keV seed는 SDE target profile을 완전히 복제하는 recipe로 확정된 것이 아니며, 실제 electrical baseline보다 VBD가 낮고 V150 diagnostic SCR이 더 깊게 나타나므로 추가 공정 calibration이 필요하다.

향후에는 공정적으로 plausible한 profile 범위 안에서 DNW Dose/Energy 및 common RTA 조건의 local sensitivity를 확인하여 공통 baseline과 전기적으로 동등한 surrogate process point를 찾는다.

## 6. 문제점 및 한계

- 현재 95 keV process seed는 최종 surrogate baseline이 아니다.
- V150 SCR metric은 15.0 V diagnostic 결과이며 공통 baseline의 최종 SCR 평가 bias와 동일하지 않을 수 있다.
- Workbench node 번호 기반 dependency는 multi-case calibration에서 잘못된 upstream mesh를 참조할 위험이 있어 주의가 필요하다.
- 80 keV diagnostic run은 SDevice convergence failure가 발생하여 최종 sensitivity 결과로 사용할 수 없다.
- 현재 사용 중인 SProcess mesh는 MID(FINE-Lite) calibration mesh이며 최종 baseline freeze 전 true-FINE 재검증이 필요하다.

## 7. 주요 결정 사항

- SProcess 결과는 SMesh를 거쳐 SDevice에 전달한다.
- B calibration에서는 geometry가 동일하므로 geometry boundary와 process profile mapping의 역할을 구분한다.
- 공통 depth coordinate는 grating/Si interface를 기준으로 관리한다.
- 95 keV PW trim 조건을 baseline process calibration seed로 사용한다.
- baseline reconstruction 단계에서는 성능 개선 지표를 선정 기준으로 사용하지 않는다.
- PEB/dark-current/ATP 최적화는 surrogate baseline freeze 이후 수행한다.
- 80 keV diagnostic 결과는 convergence issue가 포함되어 있으므로 baseline calibration 근거로 직접 사용하지 않는다.
