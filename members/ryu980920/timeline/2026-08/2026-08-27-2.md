## 3. 수행한 작업

### 3.1 SProcess surrogate baseline flow 구성

#### 작업 배경

B 연구에서는 이후 DNW Dose, DNW Energy, Common Anneal Temperature, Common Anneal Time을 변화시키고 PW Implant Energy로 SCR 위치를 baseline에 맞추는 공정 연구를 수행할 예정이다.

이를 위해 먼저 SDE에서 정의된 target doping profile을 SProcess의 implant + anneal 방식으로 재현할 수 있어야 한다.

#### 수행 내용

SProcess에서 다음 기본 흐름을 구성하고 점검하였다.

- DNW implant
- PW implant
- DNW/PW 이후 common anneal
- final doping profile 출력
- profile 비교용 PLX/FPS/TDR 생성

DNW와 PW에 서로 다른 anneal을 두지 않고, 두 implant 이후 하나의 common anneal을 사용하는 연구 조건을 유지하였다.

#### 사용한 자료 및 도구

- 소프트웨어: Sentaurus Process, Sentaurus Visual
- 참고 자료: 공통 SDE baseline의 PW/DNW target doping profile

- 검증 방법: as-implanted/final PLX 및 TDR 결과 직접 비교

### 3.2 SDE target doping profile을 calibration 기준으로 설정

#### 작업 배경

현재 공통 baseline의 실제 foundry implant dose/energy와 thermal recipe는 공개되어 있지 않다.

따라서 SProcess의 목적은 실제 ST 공정 recipe를 복원하는 것이 아니라, 이미 전기 baseline의 기준으로 사용 중인 SDE analytic PW/DNW profile을 공정적으로 재현하는 surrogate process를 만드는 것이다.

#### 수행 내용

- SDE analytic PW/DNW profile을 SProcess calibration target으로 사용하였다.
- SProcess에서 생성되는 profile의 peak 위치, peak 크기, spreading 및 junction 경향을 target과 비교하였다.
- 특정 parameter 값 자체를 실제 foundry 값으로 해석하지 않기로 하였다.

#### 작업 배경

implant 직후 profile과 common anneal 이후 profile은 diffusion 및 activation 등의 영향으로 달라지므로 두 상태를 분리해서 볼 필요가 있었다.

#### 수행 내용

- common anneal 이후 well profile
- structure/profile TDR

- `BL_FAST_CH7R4_well_r13.plx`
- `BL_FAST_CH7R4_fps.tdr`

이를 통해 implant 조건 변경이 초기 profile에 미치는 영향과 anneal 후 profile 변화가 어떻게 나타나는지 확인하였다.

### 3.4 PW/DNW profile calibration 방향 검토

#### 수행 내용

SDE target과 SProcess 결과 사이의 차이를 줄이기 위해 다음 항목을 중심으로 parameter 조정 방향을 검토하였다.

- well profile peak 위치
- peak concentration 경향
- depth 방향 spreading
- PW/DNW profile overlap 및 junction 위치
- as-implanted와 annealed profile의 차이

이 단계에서는 STI 위치를 임의로 움직여 VBD를 맞추는 방식은 사용하지 않았다.

또한 이 시점의 목적은 VBD 숫자 자체를 직접 맞추는 것이 아니라, 먼저 SProcess final doping profile을 SDE target과 충분히 유사하게 만드는 것이었다.

## 5. 해석

2026-08-27-2 작업은 B 연구에서 사용할 공정 변수 sweep 이전에 필요한 baseline process calibration 단계이다.

공개되지 않은 실제 foundry recipe를 추정값으로 채워 넣는 대신, 공통 SDE baseline의 전기적으로 의미 있는 target doping profile을 먼저 정하고 이를 SProcess의 surrogate implant/anneal 조건으로 재현하는 방향을 유지하였다.

향후 B 연구의 공정 조건을 비교하려면 모든 candidate가 동일한 구조와 평가 기준을 사용해야 하므로, 현재 단계에서는 VBD 하나만 맞추는 것보다 SDE target과의 doping-profile 정합을 먼저 확보하는 것이 중요하다.

## 6. 문제점 및 한계

- SDE target과 SProcess final profile의 정량적 오차 평가가 추가로 필요하다.
