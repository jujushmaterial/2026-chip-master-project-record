## 2. 활동 목표

2026-08-29까지 구축한 SProcess → SMesh → SDevice electrical calibration flow를 이용하여, 공통 SDE/SDevice baseline을 재현할 수 있는 surrogate process 조건을 찾기 위한 calibration sweep을 구성하는 것을 목표로 하였다.

이번 단계의 목적은 B 연구의 최종 공정 최적화가 아니라 baseline reconstruction이다. 따라서 현재 SProcess 95 keV PW trim 조건을 기준으로 DNW Dose, DNW Energy, common RTA Temperature, common RTA Time에 대한 local sensitivity를 확인하고, doping profile과 VBD/SCR의 baseline 정합성을 동시에 평가한다.

## 3. 수행한 작업

### 3.1 Baseline reconstruction용 calibration 변수 재정리

기존 SProcess seed에서는 SDE target 대비 DNW profile이 상대적으로 높고 좁은 형태로 확인되었으며, 첫 electrical validation에서 VBD가 공통 baseline 목표보다 낮게 나타났다.

현재 coarse baseline calibration에서는 PW Trim Energy를 95 keV로 유지하고 다음 변수를 중심으로 calibration set을 구성하였다.

- DNW Dose
- DNW Energy
- Common RTA Temperature
- Common RTA Time

PW Trim Energy는 이후 최종 후보에서 SCR 위치 보정이 필요할 때 dependent trim variable로 사용하는 원래 연구 방향을 유지하였다.

### 3.2 17-case calibration set 구성

Workbench Scenario를 분리하여 불필요한 Cartesian product가 생기지 않도록 calibration set을 구성하였다.

주요 비교축은 다음과 같다.

- 1050°C 기준 DNW Dose sweep
- 1050°C 기준 DNW Energy sweep
- 30 s 기준 RTA Temperature sweep
- 1050°C 기준 RTA Time sweep
- 1070°C 조건에서 selected Dose/Time combination
- 보조 결합 조건

최종적으로 총 17개의 calibration experiment를 구성하였다.

이 17-case set은 “더 좋은 SPAD 공정”을 찾기 위한 optimization DOE가 아니라, 현재 surrogate process가 공통 baseline의 doping/electrical target을 재현하도록 calibration하기 위한 데이터 확보용 set으로 정의하였다.

### 3.3 최초 17-case 실행에서 동일 결과 발생

17개 calibration case를 실행한 뒤 서로 다른 SWB parameter 값을 입력했음에도 결과가 동일하게 나타나는 문제가 발생하였다.

SProcess command의 Variables block을 다시 확인한 결과 다음 변수들이 SWB Parameter로 등록되어 있었음에도 command 내부에서는 숫자로 hard-coding되어 있음을 확인하였다.

- `DNW_DOSE`
- `DNW_E`
- `RTA_T`
- `RTA_t`

당시 `PW_TRIM_E`만 `@PW_TRIM_E@` 형식으로 연결되어 있었다.

이번 17-case에서는 PW Trim Energy도 모두 95 keV로 동일했기 때문에, 실제 SProcess 조건은 모든 experiment에서 동일한 C0 조건으로 실행되었다.

따라서 최초 17-run은 calibration dataset으로 사용하지 않고 동일조건 반복 계산으로 판정하였다.

### 3.4 SWB parameterization 규칙 수정

SProcess command를 수정하여 현재 SWB Parameter로 등록된 항목을 모두 `@PARAMETER@` 형식으로 연결하였다.

현재 적용한 SWB Parameter는 다음과 같다.

- `DNW_DOSE`
- `DNW_E`
- `PW_TRIM_E`
- `PW_FIXED_E`
- `PW_TRIM_FRAC`
- `PW_FIXED_FRAC`
- `PW_TOTAL_DOSE`
- `RTA_T`
- `RTA_t`

현재 calibration에서 실제 sweep하지 않는 PW 관련 parameter도 command에서 숫자로 hard-coding하지 않고, 각 SWB experiment row에 동일 값을 입력하여 고정하도록 규칙을 수정하였다.

또한 resolved SWB parameter 값이 SProcess log에 출력되도록 하여 각 experiment의 실제 입력조건을 확인할 수 있도록 하였다.

### 3.5 17-case calibration 재실행

SWB parameterization 수정 후 기존 17-case calibration set을 다시 실행하였다.

현재 재계산은 진행 중이며, 최종 baseline candidate 선정은 전체 case의 SProcess/SDevice 결과가 확보된 뒤 수행한다.

### 3.6 DNW Dose 증가 case의 첫 electrical sensitivity 확인

수정된 parameterized SProcess flow에서 DNW Dose가 실제로 다른 조건을 우선 실행하여 electrical sensitivity를 확인하였다.

확인된 결과는 다음과 같다.

- `DNW_DOSE = 2.94e13 cm^-2`
  - `VBD ≈ 15.025 V`
  - V150 diagnostic SCR center ≈ `228.9 nm`
  - V150 diagnostic SCR width ≈ `391.8 nm`
- `DNW_DOSE = 3.23e13 cm^-2`
  - `VBD ≈ 14.831 V`
  - V150 SCR metric 미추출

현재 surrogate baseline 주변에서는 DNW Dose 증가 시 VBD가 낮아지는 local sensitivity가 확인되었다.

### 3.7 DNW Dose 증가 case의 SCR 미추출 원인 확인

`DNW_DOSE = 3.23e13 cm^-2` case에서 VBD는 추출되었지만 SCR center/width 및 field metric이 `X`로 표시되었다.

현재 SVisualPy diagnostic은 15.0 V snapshot인 `V150_des.tdr`을 이용해 SCR을 추출한다.

하지만 해당 case는 `VBD ≈ 14.831 V`로 15.0 V보다 낮았기 때문에, SDevice의 ionization-integral breakdown criterion에 의해 V150 snapshot 생성 전에 계산이 종료되었다.

따라서 현재 SCR 미추출은 SCR이 물리적으로 사라진 것으로 해석하지 않고, V150 snapshot이 존재하지 않아 발생한 후처리 limitation으로 판단하였다.

## 4. 확인된 결과

- baseline reconstruction용 17-case calibration set을 구성하였다.
- 최초 17-run에서 SWB parameter가 SProcess command에 hard-coding되어 동일 조건이 반복 계산된 문제를 확인하였다.
- 최초 17-run은 calibration dataset에서 제외하였다.
- 현재 SWB에 등록된 9개 SProcess parameter를 모두 `@PARAMETER@` 형식으로 연결하였다.
- 수정 후 17-case calibration을 재실행 중이다.
- 첫 유효 DNW Dose sensitivity에서:
  - `2.94e13 cm^-2 → VBD ≈ 15.025 V`
  - `3.23e13 cm^-2 → VBD ≈ 14.831 V`
  를 확인하였다.
- DNW Dose 증가 case의 SCR 미추출은 V150 snapshot 미생성에 따른 extraction limitation으로 확인하였다.

## 5. 해석

현재 확인된 두 Dose point만 보면, surrogate baseline 주변에서는 DNW Dose를 증가시키면 breakdown voltage가 낮아지는 방향성이 나타났다.

이는 DNW concentration 증가가 PW/DNW junction 부근의 electric field를 강화하여 avalanche onset이 더 낮은 bias에서 발생하는 방향과 물리적으로 일치할 수 있다.

다만 현재는 두 점의 local sensitivity만 확인된 상태이므로, DNW Dose 감소 조건인 `2.65e13 cm^-2`, `2.35e13 cm^-2` 및 RTA/DNW Energy 조건 결과까지 확보한 뒤 baseline calibration 방향을 확정한다.

이번 calibration의 최종 선정 기준은 단일 VBD 개선이 아니라 다음 항목의 동시 정합이다.

- SDE target 대비 PW/DNW doping profile
- VBD
- SCR 위치/폭
- central/peripheral electric field
- avalanche onset 위치

- 현재 calibration은 MID(FINE-Lite) SProcess mesh에서 수행 중이며 최종 baseline freeze 전 true-FINE 재검증이 필요하다.
- 현재 단계는 baseline reconstruction calibration이며 B 연구의 최종 process optimization 결과로 해석하지 않는다.

## 7. 주요 결정 사항

- 현재 calibration의 목적은 공통 baseline 재현이며 최종 B-track optimization과 구분한다.
- PW Trim Energy는 coarse baseline calibration 동안 95 keV로 유지한다.
- SWB Parameter로 등록한 값은 현재 sweep 여부와 관계없이 command에서 hard-coding하지 않는다.
- 고정해서 사용하는 SWB Parameter는 각 experiment row에 동일 값을 입력하여 고정한다.
- 최초 hard-coded 17-run은 invalid calibration data로 처리한다.
- 전체 17-case 결과를 확보한 뒤 profile + VBD + SCR + field를 함께 비교하여 baseline candidate를 선정한다.
- 최종 후보는 true-FINE SProcess 재검증 후 baseline freeze 여부를 결정한다.
