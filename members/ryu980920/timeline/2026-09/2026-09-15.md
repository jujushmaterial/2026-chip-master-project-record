## 3. 수행한 작업

### 3.1 SDE baseline active doping PLX export 추가

기존 diagnostic/ATP SVisualPy에서 SDE baseline mesh를 직접 읽어 active doping profile을 추출하는 기능을 추가하였다.

비교 대상 field는 다음과 같다.

```text
BoronActiveConcentration
PhosphorusActiveConcentration
```

초기 reference cut인 `r=0 um`, `r=13 um`에 더해 central active-region PW/DNW comparison을 위해 `r=4.6875 um` cut을 추가하였다.

`r=0`은 P+ anode overlap 영향을 받을 수 있으므로 PW/DNW baseline profile의 주 비교 위치는 `r=4.6875 um`로 정리하였다.

### 3.2 SProcess PLX output 위치 정렬

SProcess에서도 동일한 radial position에서 profile을 출력하도록 정리하였다.

대표 stage는 다음과 같다.

```text
B_R_r4p6 : common WELL RTA 전
A_R_r4p6 : common WELL RTA 후
F_r4p6   : final P+ implant 및 fixed spike 이후
```

이를 통해 implant 직후/anneal 후/final profile을 동일 위치에서 비교할 수 있도록 하였다.

### 3.3 V156 SCR search window 수정

2026-09-14에 확인한 p-side crossing 누락 문제를 반영하여 V156 SCR extractor의 search lower bound를 bulk-Si surface까지 확장하였다.

기존:

```text
lo = 0.0
```

수정:

```text
SCR_SEARCH_MIN_IF = -0.300
```

따라서 grating/Si interface 기준 음수 영역에 존재하는 silicon 내부 p-side crossing도 검색할 수 있도록 하였다.

최종 baseline SCR comparison은 계속 15.6 V V156 snapshot을 기준으로 유지하였다.

### 3.4 V150 diagnostic 정리

과거 15.0 V V150 결과는 calibration 중 방향 확인용 diagnostic으로 사용했지만, 최종 common-baseline comparison에는 사용하지 않기로 한 원칙을 repository 문서와 source 구조에도 반영하였다.

최종 SCR comparison은 V156-only rule을 유지하였다.

### 3.5 SProcess → SNMesh filename compatibility 정리

SProcess final TDR basename과 SNMesh input reference가 일치하지 않는 문제를 정리하였다.

현재 SProcess output은 다음 basename을 사용한다.

```text
n@node@_fps.tdr
```

SNMesh1/SNMesh2도 이에 맞춰 upstream SProcess file을 참조하도록 수정하여 legacy basename 의존성을 제거하였다.

### 3.6 Large DOE용 PLX-only SProcess command 구축

모든 DOE case에서 중간/final TDR을 저장하면 storage와 I/O 부담이 커지므로 profile screening 전용 경량 SProcess command를 작성하였다.

이 command는:

- 중간/final TDR 저장 제거
- profile 비교용 PLX 유지
- r=0, r=4.6875, r=13 um 진단 cut 유지

방식으로 구성하였다.

TDR을 출력하지 않기 때문에 이 버전 자체를 그대로 SDevice downstream input으로 사용하지 않고, profile screening 후 선별 candidate만 TDR-enabled flow로 재실행하도록 하였다.

### 3.7 Profile Screening SVisualPy 작성

SProcess PLX와 SDE baseline target을 자동 비교하는 SVisualPy script를 작성하였다.

PW에서 추출하도록 한 주요 metric:

- peak depth
- peak concentration
- width 관련 metric
- second-peak ratio
- 특정 depth concentration
- integrated active dose
- full-profile log RMSE
- normalized shape log RMSE

DNW에서 추출하도록 한 주요 metric:

- peak depth
- peak concentration
- FWHM
- half-max position
- equivalent sigma
- 특정 depth concentration
- integrated active dose
- full-profile log RMSE
- normalized shape log RMSE

joint metric으로 PW/DNW metallurgical crossing 등도 확인하도록 하였다.

단, `BActive = PActive` crossing은 SCR center와 동일시하지 않는다.

### 3.8 Profile-first Large DOE flow 확정

대규모 calibration의 실행 순서를 다음과 같이 정리하였다.

```text
1. SProcess DOE 실행
2. 각 case PLX 저장
3. SVisualPy profile metric 추출
4. SDE baseline 대비 profile error 비교
5. 상위 candidate screening
6. 선별 candidate만 TDR-enabled SProcess로 재실행
7. SDevice에서 VBD 및 V156 SCR 검증
```

즉 모든 DOE case를 처음부터 SDevice까지 계산하지 않고 profile screening을 먼저 수행하는 구조로 전환하였다.

## 5. 해석

baseline reconstruction의 중심을 단순 VBD matching에서 `doping-profile equivalence + electrical equivalence`로 확장하였다.

2026-09-14까지는 개별 PLX를 직접 비교하며 profile mismatch를 확인했다면, 이번 작업에서는 동일 radial cut과 자동 metric을 사용해 더 많은 candidate를 일관되게 screening할 수 있는 분석 환경을 구축하였다.

다만 이 환경을 구축한 것이 곧 최종 surrogate baseline을 확보했다는 의미는 아니다.

## 6. 문제점 및 한계

- Large DOE 전체 결과 분석은 아직 완료되지 않았다.
- profile screening 통과가 electrical equivalence를 보장하지 않는다.
- RTA Temperature/Time의 profile sensitivity는 별도 정량 검증이 필요하다.
- 최종 candidate는 TDR-enabled SProcess와 SDevice에서 재검증해야 한다.
- true-FINE 재검증과 baseline freeze는 아직 남아 있다.

## 7. 주요 결정 사항

- SDE–SProcess PW/DNW profile의 주 비교 위치는 r=4.6875 um를 사용한다.
- 최종 SCR comparison은 15.6 V V156 기준으로 유지한다.
- V150 diagnostic은 최종 baseline comparison에 사용하지 않는다.
- Large DOE는 profile-first screening을 적용한다.
- profile candidate를 선별한 뒤 SDevice에서 VBD/SCR을 검증한다.
- metallurgical crossing과 SCR center를 동일시하지 않는다.
- 현재 등록된 SWB Parameter는 command에서 숫자로 hard-coding하지 않는다.
