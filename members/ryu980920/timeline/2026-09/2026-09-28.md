특히 다음 항목을 중심으로 각 process variable의 역할을 분리하여 해석하였다.

분석 결과를 바탕으로 다음 calibration에서는 어떤 parameter를 어느 방향으로 이동시켜야 하는지 결정하고 새로운 탐색 범위를 설정하는 것을 목표로 하였다.


## 3. 수행한 작업

### 3.1 Dual-DNW 결과 CSV 확인

기존에는 다음 조건으로 총 96개 Dual-DNW 조합을 계획하였다.

- DNW_DOSE = 2.60e13 / 2.80e13 / 3.00e13 cm^-2
- DNW_E = 935 / 955 keV
- DNW_TRIM_E = 650 / 750 keV
- DNW_TRIM_FRAC = 0.15 / 0.25 / 0.35 / 0.45
- PW_TRIM_FRAC = 0.500 / 0.525

그러나 실제 결과 CSV를 확인한 결과 64개 조건만 존재하였다.

원인을 확인한 결과 `DNW_DOSE = 2.80e13 cm^-2` 조건이 전체적으로 빠져 있었고, 실제 결과는 다음 조합으로 구성되어 있었다.

2 Dose × 2 Main Energy × 2 Trim Energy × 4 Trim Fraction × 2 PW Trim Fraction = 64

따라서 오늘의 경향성 분석은 `DNW_DOSE = 2.60e13 / 3.00e13 cm^-2` 두 수준에 대해서 수행하였다.


### 3.2 Dual-DNW 적용 효과 확인

기존 250-point single-energy DNW DOE에서 가장 넓은 DNW equivalent sigma는 약 279.7 nm였다.

이번 Dual-DNW 결과에서는 최대 약 297.3 nm까지 증가하였다.

즉 최대 width 기준으로 약 17.6 nm, 약 6.3% 증가하였다.

SDE target DNW sigma는 약 380.6 nm이므로 아직 target에는 도달하지 못했지만, Dual-DNW를 도입함으로써 기존 single-energy DNW보다 profile width를 넓힐 수 있는 추가 자유도가 확보된 것은 확인하였다.

또한 실제 profile에서는 두 개의 분리된 DNW peak가 형성되기보다 main peak와 shallow-side tail이 연결된 형태가 나타났다.

따라서 현재 Dual-DNW는 별도의 두 peak를 만드는 것이 아니라, main DNW profile에 shallow phosphorus contribution을 추가하는 방향으로 작동하고 있다고 판단하였다.


### 3.3 DNW Dose 경향 분석

DNW total dose를 2.60e13에서 3.00e13 cm^-2로 증가시키면 SDE junction 위치 부근의 phosphorus 농도는 증가하였다.

즉 junction-side tail 농도 자체는 증가하였다.

그러나 동시에 다음 현상이 나타났다.

- DNW peak concentration 증가
- DNW equivalent sigma 감소
- PW/DNW crossing 위치가 더 shallow하게 이동

평균 DNW peak ratio는 약 1.42에서 1.66으로 증가하였고, DNW sigma는 약 283.7 nm에서 279.1 nm로 감소하였다.

따라서 현재 DNW mismatch의 핵심은 phosphorus 총량 부족이 아니라, phosphorus가 main peak 부근에 지나치게 집중되어 있다는 점으로 판단하였다.

이에 따라 다음 calibration에서는 DNW Dose를 더 높이는 방향보다 낮거나 중간 수준에서 유지하는 것이 적절하다고 판단하였다.


### 3.4 DNW Main Energy 경향 분석

DNW_E를 935에서 955 keV로 증가시키면 DNW main peak가 deeper 방향으로 이동하였다.

동시에:

- DNW peak 위치가 SDE target 방향으로 이동
- DNW peak concentration이 일부 감소
- DNW width가 소폭 증가
- junction-side slope가 소폭 개선

되는 경향이 나타났다.

따라서 DNW Main Energy는 약 1 um 부근의 main peak 위치를 유지하거나 deeper 방향으로 보정하는 변수로 사용하는 것이 적절하다고 판단하였다.

현재 최대값인 955 keV에서도 개선 방향이 유지되었으므로 다음 calibration에서는 Main Energy를 더 높은 영역까지 확장하기로 하였다.


### 3.5 DNW Trim Energy 경향 분석

DNW_TRIM_E를 750에서 650 keV로 낮추면 shallow-side phosphorus contribution이 크게 증가하였다.

650 keV 조건에서는 750 keV 대비:

- DNW equivalent sigma 증가
- SDE junction 위치에서의 PActive 증가
- junction-side tail 강화

가 나타났다.

반면 DNW global peak 위치와 PW/DNW crossing은 shallow 방향으로 이동하였다.

따라서 낮은 Trim Energy는 현재 부족한 junction-side tail을 보강하는 데 효과적이지만, main DNW까지 shallow하게 끌어당기는 문제가 함께 존재한다고 판단하였다.

이에 따라 다음 calibration에서는 Trim Energy를 더 낮추되, Main Energy를 동시에 높여 두 implant의 역할을 더 분리하는 방향으로 진행하기로 하였다.


### 3.6 DNW Trim Fraction 경향 분석

DNW_TRIM_FRAC을 증가시키면 total DNW dose 내에서 shallow Trim implant의 비중이 증가하고 Main implant의 비중은 감소한다.

Trim Fraction이 증가하면서 다음 경향이 나타났다.

- junction-side PActive 증가
- DNW width 증가
- DNW main/global peak가 shallow 방향으로 이동

특히 DNW sigma 평균은:

- 0.15: 약 277.0 nm
- 0.25: 약 281.2 nm
- 0.35: 약 283.6 nm
- 0.45: 약 283.8 nm

로 나타났다.

0.35 이후에는 width 증가가 거의 포화되었지만 DNW peak 위치는 계속 shallow하게 이동하였다.

DNW peak 위치 평균은:

- 0.15: 약 988.9 nm
- 0.25: 약 954.6 nm
- 0.35: 약 917.9 nm
- 0.45: 약 885.6 nm

까지 이동하였다.

따라서 높은 Trim Fraction에서는 width 증가 효과보다 main peak 위치를 망가뜨리는 영향이 더 커지는 것으로 판단하였다.

다음 calibration에서는 높은 fraction 영역을 제외하고 0.10 ~ 0.25의 낮은 범위를 세분화하여 확인하기로 하였다.


### 3.7 현재 가장 가까운 profile의 한계 확인

현재 64개 중 가장 낮은 score를 가진 조건은 다음과 같았다.

- DNW_DOSE = 2.60e13 cm^-2
- DNW_E = 955 keV
- DNW_TRIM_E = 650 keV
- DNW_TRIM_FRAC = 0.15

이 조건에서:

- DNW peak 위치 ≈ 1000 nm
- SDE target ≈ 1017.3 nm
- DNW sigma ≈ 285.5 nm
- SDE target ≈ 380.6 nm
- PW/DNW crossing ≈ 425.2 nm
- SDE target ≈ 462.7 nm

이었다.

즉 DNW main peak 위치는 SDE target에 상당히 가까워졌지만, profile width가 부족하고 junction-side phosphorus tail이 충분하지 않아 crossing이 약 37 nm shallow하게 형성되었다.

따라서 다음 단계에서의 핵심 목표를 다음과 같이 정의하였다.

`main peak 위치는 유지하면서 junction-side tail과 profile width만 추가로 증가시키는 것`


### 3.8 다음 calibration 범위 선정

오늘 확인한 경향을 기반으로 다음 parameter 역할을 다음과 같이 정리하였다.

- DNW Dose: 전체 phosphorus 농도 수준 조절
- DNW Main Energy: main peak depth 조절
- DNW Trim Energy: shallow-side tail 위치 조절
- DNW Trim Fraction: shallow tail의 세기 조절

따라서 다음 calibration은 다음 방향으로 설정하였다.

#### DNW_DOSE

`2.40e13 / 2.60e13 / 2.80e13 cm^-2`

3.00e13에서는 DNW peak concentration이 과도하게 증가하고 width가 오히려 감소하는 경향이 확인되었다.

따라서 높은 Dose를 추가 탐색하지 않고 2.60e13 이하와 기존에 누락된 2.80e13을 중심으로 확인한다.

#### DNW_E

`955 / 975 / 995 keV`

935 → 955 keV에서 main peak가 deeper 방향으로 이동하고 width가 소폭 개선되는 경향이 확인되었다.

따라서 더 높은 Main Energy를 이용하여 shallow Trim implant가 추가되더라도 약 1 um 부근의 main peak를 유지할 수 있는지 확인한다.

#### DNW_TRIM_E

`550 / 600 / 650 keV`

750 → 650 keV에서 junction-side tail과 DNW width가 개선되었다.

따라서 Trim implant를 더욱 shallow하게 이동시켜 현재 부족한 junction-side phosphorus tail을 추가로 확보할 수 있는지 확인한다.

#### DNW_TRIM_FRAC

`0.10 / 0.15 / 0.20 / 0.25`

기존 0.35 ~ 0.45 영역에서는 width 증가가 포화되는 반면 main peak shallow shift는 계속 증가하였다.

따라서 높은 fraction을 제외하고, Main DNW를 유지하면서 tail만 보강할 수 있는 낮은 fraction 영역을 더 세밀하게 탐색한다.


## 4. 확인된 결과

- 계획한 96개 조건 중 실제 결과는 64개였으며 DNW_DOSE = 2.80e13 조건이 누락되어 있음을 확인하였다.
- Dual-DNW 도입 후 최대 DNW sigma가 기존 single-energy DNW 대비 약 17.6 nm 증가하였다.
- Dual-DNW가 DNW profile width와 shallow-side tail을 조절할 수 있는 추가 자유도를 제공함을 확인하였다.
- DNW Dose 증가는 junction-side 농도를 높이지만 peak 과다와 width 감소를 동반하였다.
- DNW Main Energy 증가는 main peak를 deeper 방향으로 유지하는 데 효과적이었다.
- DNW Trim Energy 감소는 DNW width와 junction-side tail 개선에 가장 효과적인 방향 중 하나였다.
- DNW Trim Fraction 증가는 tail을 강화하지만 높은 fraction에서는 width 개선이 포화되고 main peak shallow shift가 지배적이 되었다.
- 현재 가장 가까운 조건은 DNW peak 위치는 비교적 잘 맞지만 width와 junction-side tail이 여전히 부족하였다.
- 다음 calibration에서는 Main Energy를 높이고 Trim Energy를 낮추며 Trim Fraction을 낮은 영역으로 제한하는 방향으로 진행하기로 하였다.


## 5. 해석

이번 결과에서 가장 중요한 점은 Dual-DNW를 도입함으로써 기존 single-energy DNW에서 부족했던 profile-shape freedom이 실제로 증가했다는 것이다.

그러나 현재 변수 범위에서는 tail을 강화할수록 DNW main peak가 함께 shallow하게 이동하는 coupling이 존재하였다.

따라서 단순히 Trim dose를 더 많이 주는 방식으로는 target profile을 재현하기 어렵다.

다음 단계에서는 Main implant와 Trim implant의 역할을 더욱 분리한다.

- 높은-energy Main DNW는 약 1 um 부근 main peak를 유지
- 낮은-energy Trim DNW는 junction-side tail을 보강
- Trim Fraction은 main peak를 이동시키지 않을 정도로 제한

이 방향을 통해 기존 profile에서 부족했던 width와 junction-side tail을 증가시키면서 DNW main peak 위치는 유지하는 것을 목표로 한다.


## 6. 문제점 및 한계

- DNW_DOSE = 2.80e13 조건이 누락되어 Dose 경향을 세 수준으로 비교하지 못하였다.
- 현재 최대 DNW sigma 약 297.3 nm는 SDE target 약 380.6 nm보다 여전히 작다.
- junction-side tail을 강화할수록 PW/DNW crossing이 반드시 target 방향으로 이동하는 것은 아니다.
- 현재 결과는 profile calibration 단계이며 electrical equivalence를 의미하지 않는다.
- 최종 DNW 조건 선정 후에는 PW 조건을 조절하여 SCR/junction 위치를 다시 정합해야 한다.
