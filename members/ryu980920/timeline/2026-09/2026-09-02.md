## 2. 활동 목표

기존 17-case surrogate baseline calibration 결과를 확인하여 공통 electrical baseline에 가까운 공정영역을 좁히고, 해당 경향을 바탕으로 14개의 refinement calculation set을 새로 구성하는 것을 목표로 하였다.

또한 기존 V150 기반 diagnostic SCR은 공통 baseline의 15.6 V SCR과 동일 bias에서 직접 비교할 수 없으므로, 15.6 V 이상까지 계산 가능한 candidate에서 V156 snapshot을 이용해 SCR 위치를 직접 추출할 수 있도록 SDevice/SVisualPy 분석 flow를 수정하였다.

이번 단계는 B-track 성능 최적화가 아니라 surrogate baseline reconstruction의 refinement 단계이다.

## 3. 수행한 작업

### 3.1 17-case calibration 결과 확인

#### 수행 내용

수정된 17-case calibration 결과를 확인하여 DNW Dose, DNW Energy, Common RTA Temperature, Common RTA Time 변화에 따른 VBD 경향을 비교하였다.

현재 결과에서 확인된 local trend는 다음과 같다.

- DNW Dose 감소 방향에서 VBD가 증가하는 경향 확인
- DNW Energy 증가 방향에서 VBD가 증가하는 경향 확인
- RTA Temperature/Time 변화도 VBD에 영향을 주지만 현재 sweep 범위에서는 DNW Energy/Dose 변화보다 상대적으로 작은 sensitivity를 보임

이 경향은 현재 surrogate baseline 주변의 local calibration 결과이며 일반적인 공정 법칙으로 확장하지 않는다.

### 3.2 VBD 기준 유력 공정영역 확인

공통 baseline의 frozen VBD target은 약 `15.798 V`이다.

17-case 결과 중 VBD 기준으로 가장 가까운 조건은 다음과 같이 확인하였다.

```text
RTA_T       = 1070 °C
RTA_t       = 30 s
DNW_E       = 960 keV
DNW_DOSE    = 2.65e13 cm^-2
PW_TRIM_E   = 95 keV
VBD         ≈ 15.883 V
```

baseline target 대비 VBD 차이는 약 `+0.085 V`이다.

다만 이 조건은 현재 단계에서 **VBD 기준 유력 조건**일 뿐 최종 surrogate baseline candidate로 확정하지 않았다. 최종 선정에는 15.6 V 기준 SCR 위치/폭, electric field, avalanche position 및 profile plausibility를 함께 확인해야 한다.

### 3.3 14-case refinement calculation set 구성

17-case에서 확인한 경향을 이용하여 baseline target 근처를 더 촘촘히 확인할 수 있도록 총 14개의 unique experiment를 구성하였다.

#### Scenario 1 — DNW Energy × Dose refinement

공통 조건:

```text
RTA_T         = 1070 °C
RTA_t         = 30 s
PW_TRIM_E     = 95 keV
PW_FIXED_E    = 32 keV
PW_TRIM_FRAC  = 0.65
PW_FIXED_FRAC = 0.35
PW_TOTAL_DOSE = 2.06e13 cm^-2
```

Sweep:

```text
DNW_E    = 950 / 955 / 960 keV
DNW_DOSE = 2.55e13 / 2.65e13 / 2.75e13 cm^-2
```

`3 × 3` full-factorial로 총 9개의 experiment를 구성하였다.

#### Scenario 2 — RTA Temperature refinement

공통 중심조건:

```text
RTA_t      = 30 s
DNW_E      = 955 keV
DNW_DOSE   = 2.65e13 cm^-2
PW_TRIM_E  = 95 keV
```

추가 계산점:

```text
RTA_T = 1050 / 1060 / 1080 °C
```

`1070 °C` 중심점은 Scenario 1의 공통 중심 experiment를 공유하여 중복 계산하지 않는다.

#### Scenario 3 — RTA Time refinement

공통 중심조건:

```text
RTA_T      = 1070 °C
DNW_E      = 955 keV
DNW_DOSE   = 2.65e13 cm^-2
PW_TRIM_E  = 95 keV
```

추가 계산점:

```text
RTA_t = 20 / 40 s
```

`30 s` 중심점은 Scenario 1의 공통 중심 experiment를 공유한다.

따라서 Scenario별 표시점은 겹치지만 실제 unique experiment는 총 14개이며, 현재 해당 14-case refinement 계산을 진행 중이다.

### 3.4 15.6 V SCR extraction 필요성 재정리

기존 calibration SVisualPy는 candidate의 VBD가 15.6 V보다 낮은 경우에도 SCR 이동 방향을 확인하기 위해 `V150_des.tdr`을 이용한 15.0 V diagnostic extraction을 사용하였다.

그러나 최종 surrogate baseline candidate는 공통 baseline과 같은 bias 조건에서 SCR을 비교해야 하므로 V150 결과를 baseline의 15.6 V SCR과 직접 비교할 수 없다.

따라서 이번 refinement 계산에서는 VBD가 15.6 V 이상인 candidate를 대상으로 15.6 V snapshot에서 SCR을 직접 평가하도록 분석 flow를 수정하였다.

### 3.5 SDevice의 15.6 V 이상 snapshot 사용

SDevice에서는 기존 baseline diagnostic physics와 ionization-integral breakdown definition을 유지하였다.

주요 설정은 다음과 같다.

- `Avalanche(vanOverstraeten GradQuasiFermi)`
- `AvalPostProcessing`
- `BreakAtIonIntegral`
- `ComputeIonizationIntegrals(direction="eGradQuasiFermi")`

또한 기존 bias sweep의 `V156` snapshot을 그대로 이용하여 15.6 V static state를 SVisualPy가 읽을 수 있도록 하였다.

SDevice의 breakdown physics 자체를 새로운 모델로 변경한 것이 아니라, 15.6 V 이상 candidate에서 기존 `V156_des.tdr`을 SCR 비교에 사용할 수 있도록 한 것이다.

### 3.6 SVisualPy를 15.6 V SCR extraction용으로 수정

기존 V150 diagnostic SVisualPy를 다음과 같이 변경하였다.

```text
EVAL_BIAS = 15.6
TDR_FILE  = n{SDevice node}_V156_des.tdr
```

현재 SProcess → SMesh 좌표계는 그대로 유지하였다.

```text
bulk-Si surface              raw y = 0.000 um
grating/Si interface anchor  raw y = 0.300 um
project common depth         z_if = raw_y - 0.300 um
```

15.6 V state에서 다음 metric을 Workbench DOE로 추출하도록 구성하였다.

```text
VBD_V
SCR_p_nm
SCR_center_nm
SCR_n_nm
SCR_width_nm
Aval_peak_nm
Ecenter_kVpcm
Eperiph_kVpcm
R_E
SCR_OK
```

SCR boundary는 기존 baseline extraction과 동일하게 center radial cutline에서 net-doping junction을 기준으로 `|E| = 1.0e5 V/cm` crossing을 이용한다.

### 3.7 VBD가 15.6 V 이하인 candidate의 처리

SDevice는 `BreakAtIonIntegral`을 사용하므로 candidate의 breakdown이 15.6 V보다 먼저 발생하면 `V156_des.tdr`이 생성되지 않을 수 있다.

이 경우 다른 bias의 SCR을 대신 사용하지 않고 다음과 같이 처리하도록 하였다.

```text
SCR_p_nm      = NA
SCR_center_nm = NA
SCR_n_nm      = NA
SCR_width_nm  = NA
SCR_OK        = 0
```

따라서 최종 15.6 V SCR comparison에서 서로 다른 bias의 SCR이 혼합되지 않도록 하였다.

## 5. 해석

17-case coarse calibration을 통해 baseline target에 접근할 수 있는 DNW Energy/Dose 공정영역을 좁힐 수 있었다.

현재 결과에서는 DNW Energy와 Dose가 VBD에 가장 명확한 local sensitivity를 보였기 때문에, 14-case refinement에서는 두 변수를 중심으로 `3 × 3` local grid를 구성하고 RTA Temperature/Time은 중심조건 주변의 추가 sensitivity 확인으로 배치하였다.

다만 VBD가 baseline에 가까운 것만으로 surrogate baseline을 선정하지 않는다.

최종 candidate는 다음 항목을 동시에 비교하여 판단한다.

- VBD proximity
- 15.6 V SCR position
- SCR width
- central/peripheral electric field
- avalanche peak position
- SProcess profile plausibility

현재 14-case 계산이 완료되지 않았으므로 최종 surrogate baseline candidate는 아직 확정하지 않는다.

## 6. 문제점 및 한계

- 현재 단계는 baseline reconstruction이며 PEB, dark current, ATP 개선을 목표로 하는 B-track optimization 단계가 아니다.

## 7. 주요 결정 사항

- 17-case 결과의 local trend를 이용해 baseline target 주변을 14-case refinement set으로 재구성한다.
- PW Trim Energy는 이번 refinement에서도 95 keV로 유지한다.
- PW 관련 고정값도 SWB Parameter 상태를 유지하고 experiment row에서 동일 값으로 고정한다.
- 15.6 V 이상 candidate의 SCR은 V156 snapshot에서 직접 추출한다.
- V156이 존재하지 않는 candidate는 다른 bias의 SCR로 대체하지 않는다.
- 최종 baseline candidate는 VBD 단독이 아니라 SCR/field/avalanche/profile을 함께 비교한 뒤 선정한다.
- 최종 candidate 확정 후 필요할 경우 PW Trim Energy를 dependent correction variable로 사용하여 SCR 위치를 미세 보정한다.
