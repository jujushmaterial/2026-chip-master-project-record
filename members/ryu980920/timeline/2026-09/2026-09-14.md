## 3. 수행한 작업

### 3.1 DOE 결과를 세 그룹으로 구분

분석 대상은 다음 세 그룹으로 구분하였다.

- Project A: DNW Dose × DNW Energy correction DOE
- Project B: PW Fixed Energy × PW trim/fixed fraction DOE
- Project C: DNW/PW correction을 결합한 candidate

각 그룹에서 VBD, SCR 및 관련 electrical metric을 비교하였다.

### 3.2 SCR 미추출 case 원인 분석

CSV 결과에서 일부 case의 SCR metric이 누락된 것을 확인하고 SVisualPy extraction logic을 추적하였다.

기존 coordinate 정의는 다음과 같았다.

```text
z_if = y_raw - 0.300 um
SCR threshold = |E| = 1.0e5 V/cm
search lower bound = 0
```

이 조건에서는 p-side crossing이 grating/Si interface 기준으로 약간 음수 영역에 위치할 경우 crossing을 찾지 못해 `SCR_OK=0`이 될 수 있음을 확인하였다.

대표적으로 확인한 case에서는 p-side crossing이 약 `-2.18 nm`, n-side crossing이 약 `419.20 nm`에 위치하였다.

bulk-Si surface까지 물리적 silicon 영역을 포함해 해석하면 해당 case의 SCR은 대략 다음과 같이 계산되었다.

```text
SCR center ≈ 208.5 nm
SCR width  ≈ 421.4 nm
```

따라서 이 누락을 SCR이 물리적으로 존재하지 않는 것으로 해석하지 않고, 후처리 search-window limitation으로 판단하였다.

### 3.3 PW 3×3 DOE의 9개 PLX 직접 비교

PW profile DOE의 9개 PLX를 직접 비교하였다.

Sweep 축은 다음과 같다.

```text
PW_FIXED_E =
32 / 36 / 40 keV

PW_TRIM_FRAC =
0.65 / 0.60 / 0.55
```

PW_TOTAL_DOSE는 해당 DOE의 설정값으로 유지하고 trim/fixed fraction 조합을 비교하였다.

총 `3 × 3 = 9`개의 PW profile을 비교하였다.

### 3.4 PW Fixed Energy 영향 확인

PW_FIXED_E가 증가할수록 shallow PW peak가 더 깊어지는 경향을 확인하였다.

PLX에서 확인한 대표적인 peak-depth 변화는 대략 다음과 같았다.

```text
약 90 nm
→ 110 nm
→ 140 nm
```

이는 해당 3×3 DOE 범위의 local profile trend이다.

### 3.5 PW trim/fixed fraction 영향 확인

PW_TRIM_FRAC을 낮추고 fixed fraction을 높이면 다음과 같은 profile 변화가 나타났다.

- shallow main peak 증가
- bulk-side tail 감소

즉 fraction 조절로 main peak와 deeper tail 사이의 상대적인 weight를 조정할 수 있음을 확인하였다.

### 3.6 SDE baseline 대비 profile mismatch 분석

9개 PW profile을 SDE baseline target과 비교하였다.

현재 DOE에서는 전반적으로 다음 mismatch가 남아 있었다.

- 약 100–300 nm 구간에서 PW 농도가 상대적으로 높은 경향
- 약 350–500 nm deeper tail이 상대적으로 부족한 경향

따라서 peak 위치 하나만 맞추는 것으로는 PW baseline reproduction이 충분하지 않으며, peak amplitude와 bulk-side tail을 함께 맞춰야 한다고 판단하였다.

### 3.7 PW candidate ranking

9개 case 중 profile 및 electrical result를 함께 검토하여 후속 candidate 우선순위를 정리하였다.

당시 비교에서는 `n260`을 1순위, `n267`을 2순위 후보로 보았지만, 두 case 모두 SDE baseline의 peak/tail과 electrical target을 동시에 완전히 만족한 최종 baseline은 아니었다.

따라서 이 ranking은 다음 DOE/보정 방향을 정하기 위한 intermediate screening으로만 사용하였다.

## 5. 해석

이날 분석을 통해 baseline reconstruction에서 단순히 VBD와 SCR을 맞추는 것만으로는 충분하지 않고, SDE analytic target과 SProcess PW profile shape의 직접 비교가 필요하다는 점이 명확해졌다.

특히 PW_FIXED와 PW_TRIM은 각각 main peak와 deeper tail에 서로 다른 영향을 주므로, 두 성분의 energy/fraction뿐 아니라 필요할 경우 total dose까지 포함해 amplitude와 shape를 함께 보정해야 한다.

- 9개 DOE 결과를 final baseline으로 확정하지 않는다.
