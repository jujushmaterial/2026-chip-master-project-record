### 3.2 우수 후보군의 deep-side tail 부족 확인
n72와 n124의 PActive profile을 SDE target과 깊이별로 비교하였다. Main peak 주변은 상당히 정합되었지만 깊은 방향으로 갈수록 phosphorus concentration이 빠르게 부족하였다.

대표적으로 확인한 SDE 대비 deep-tail ratio는 다음 수준이었다.

```text
1.2 um 부근 : 약 0.89
1.4 um 부근 : 약 0.48
1.6 um 부근 : 약 0.28
```

즉 Dual-DNW는 약 1 um 부근 main peak는 비교적 잘 맞췄지만 1.4~1.6 um 이후 deep tail은 충분히 재현하지 못하였다.

위 1.2/1.4/1.6 µm의 비율과 다음 절의 n72→n124 위치별 비율은 **당시 PLX 분석 기록의 근사값**이다. `0928A/B.csv`에는 TAIL14_R/TAIL16_R/TAIL18_R가 없으므로 이를 CSV에서 직접 추출한 값이라고 주장하지 않는다. PLX 원본을 다시 열 수 있을 때 기준 curve 및 각 node를 대조한다.

### 3.3 Main Energy 증가 효과와 한계 확인
n72에서 n124로 Main DNW Energy를 975 keV에서 995 keV로 증가시키면 deep-side PActive는 일부 증가하였다.

```text
1.4 um : 약 0.423 -> 0.477
1.6 um : 약 0.250 -> 0.279
```

그러나 개선 폭은 제한적이었다. 또한 Main Energy는 원래 main peak 위치를 담당하므로 이를 계속 증가시키면 이미 정합한 main peak까지 함께 이동할 수 있다.

따라서 `Main Energy 증가 -> deep tail 일부 개선 + main peak 이동 가능성`이라는 coupling이 존재한다고 판단하였다. Deep tail을 독립적으로 조절할 추가 자유도가 필요하였다.

### 3.4 Triple-DNW 구조 도입
108-case 분석에서 확인된 deep-tail 부족을 해결하기 위해 DNW를 다음 세 역할로 분리하였다.

```text
Shallow / Trim DNW -> junction-side / shallow-side contribution
Main DNW           -> 약 1 um 부근 main peak
Deep DNW           -> 1.4~1.8 um deep-side tail
```

Triple-DNW는 실제 foundry recipe 복원이 아니라 SDE surrogate baseline target profile 재현을 위한 추가 process degree of freedom이다.

기존 profile core를 보존하기 위해 n72를 기준으로 사용하였다.

```text
DNW_E       = 975 keV 고정
DNW_TRIM_E  = 550 keV 고정

Main absolute dose    = 1.80e13 cm^-2
Shallow absolute dose = 6.00e12 cm^-2
```

### 3.5 Deep dose 추가에 따른 fraction 재계산
Deep implant를 추가하면 total DNW dose가 증가하므로 기존 `DNW_TRIM_FRAC=0.25`를 그대로 유지하면 Shallow absolute dose까지 증가한다.

따라서 각 DOE row에서 다음 관계를 사용하였다.

```text
DNW_DOSE
= 1.80e13 + 6.00e12 + Deep Dose

DNW_TRIM_FRAC
= 6.00e12 / DNW_DOSE

DNW_DEEP_FRAC
= Deep Dose / DNW_DOSE
```

Main fraction은 SProcess 내부에서:

```text
DNW_MAIN_FRAC
= 1 - DNW_TRIM_FRAC - DNW_DEEP_FRAC
```

으로 계산한다.

따라서 Deep Dose가 증가하면서 `DNW_TRIM_FRAC`이 감소하더라도 실제 Shallow dose는 계속 `6.00e12 cm^-2`, Main dose는 `1.80e13 cm^-2`로 유지된다.

### 3.6 SProcess / SWB Parameter 확장
기존 Dual-DNW parameter에 다음 두 parameter를 추가하였다.

```text
DNW_DEEP_E
DNW_DEEP_FRAC
```

Main, Shallow, Deep 세 phosphorus implant는 동일한 DNW mask를 사용하고 서로 별도 anneal을 적용하지 않는다. 기존 원칙대로 DNW/PW/NW implant 이후 하나의 common WELL RTA를 적용한다.

### 3.7 SVisualPy deep-tail metric 확장
기존 Dual-DNW SCORE 구조는 유지하여 기존 결과와 비교 가능하도록 하였다. 대신 Triple-DNW의 deep-tail 효과를 직접 평가할 수 있도록 다음 metric을 추가하였다.

```text
TAIL14_R
TAIL16_R
TAIL18_R
TAIL_RMSE
```

각각 1.4/1.6/1.8 um 위치의 `SProcess PActive / SDE target` ratio와 1.2~1.8 um deep-tail 구간 log RMSE이다.

기존 `DNW_RP`, `DNW_PK_R`, `DNW_SIG`, `JUNC`, `P462_R`, `SPLIT`도 그대로 유지하였다. Deep tail이 좋아지더라도 main peak가 이동하거나 second lobe가 생기는 조건을 제외하기 위함이다.

새 tail metric은 이번 단계에서는 기존 composite SCORE에 추가하지 않았다.

### 3.8 Triple-DNW 후속 DOE 설계

```text

```

Deep Energy:
```text

```

Deep Dose (각 DOE row의 fraction을 이해하기 위한 absolute-dose 환산값):
```text
1.0e12 / 1.5e12 / 2.0e12 / 2.5e12 / 3.0e12
3.5e12 / 4.0e12 / 4.5e12 / 5.0e12 cm^-2
```

실제 SWB 입력에서는 `DNW_DOSE`, `DNW_TRIM_FRAC`, `DNW_DEEP_FRAC`을 행별로 지정했다. Main/Trim absolute dose를 일정하게 유지하면서 Deep Dose를 추가했으므로 total DNW dose는 2.50e13~2.90e13 cm^-2로 함께 증가한다. 이때 `DNW_TRIM_FRAC = 6.00e12/DNW_DOSE`, `DNW_DEEP_FRAC = Deep Dose/DNW_DOSE`이다.

### 3.11 SProcess mesh scale 확인

Stage 1 공통 STI seed의 실제 SProcess command에서 `mgoals on min.normal.size=3<nm> max.lateral.size=0.50<um> normal.growth.ratio=1.4`를 확인하였다. 아래의 깊이별 mesh anchor는 당시 기록의 근사값이며 mesh-convergence 결과를 의미하지 않는다.

현재 Triple-DNW는 Stage 1 common STI seed의 mesh를 restart TDR로 이어받는다.

주요 Stage 1 설정은:

```text
min.normal.size   = 3 nm
max.lateral.size  = 0.50 um
normal.growth.ratio = 1.4
```

depth 방향 anchor는 대략 다음 수준이다.

```text
surface / Upper-Si / BOX 인접부 : 3~5 nm
0.1~0.7 um 영역                : 약 8~10 nm
약 1.0 um DNW main 영역         : 약 15 nm
약 1.6 um deep-tail 영역        : 약 40 nm anchor
```

이번 screening은 기존 Dual-DNW와 동일 mesh framework를 사용하여 비교 일관성을 유지한다. 다만 최종 후보 freeze 전에는 1.2~1.8 um deep-tail 영역의 mesh convergence 확인이 필요하다.

## 5. 해석
오늘 작업의 핵심은 단순히 implant 하나를 추가한 것이 아니라, 108-case 결과 분석에서 확인된 profile mismatch를 바탕으로 process parameterization을 확장한 것이다.

Dual-DNW는 main peak와 shallow-side profile을 상당 부분 조절할 수 있었지만 우수 후보에서도 deep-side tail이 부족하였다. Main Energy 증가만으로는 tail 개선량이 충분하지 않았고 main peak와의 coupling도 존재하였다.

따라서 Shallow, Main, Deep implant의 역할을 분리하였다. 이번 45-case DOE는 기존에 맞춘 Main/Trim을 다시 탐색하는 단계가 아니라 새 Deep component가 현재 mismatch를 해결할 수 있는지를 검증하는 calibration 단계이다.

## 6. 문제점 및 한계
- Triple-DNW는 아직 최종 surrogate baseline recipe가 아니다.
- `DNW_DEEP_E = 1300~1700 keV`는 실제 foundry 값이 아니라 surrogate exploration range이다.
- Deep Dose `1.0e12~5.0e12 cm^-2`도 calibration range이다.
- deep-tail metric의 target reference는 현재 SVisualPy reference 체계를 사용하며 full SDE PLX 직접 연동은 아직 아니다.
- Deep tail을 증가시키는 과정에서 main peak 이동이나 second lobe가 발생할 수 있다.
- deep-tail 영역 mesh가 main/junction 영역보다 상대적으로 성기므로 최종 후보에서 mesh convergence 검증이 필요하다.
- profile matching만으로 electrical equivalence를 주장할 수 없으며 최종 후보는 SDevice 검증이 필요하다.

## 7. 주요 결정 사항
- 108-case 결과의 우수 후보 중 n72를 Triple-DNW refinement 기준으로 사용한다.
- n124는 Main Energy 증가에 따른 deep-tail 변화 비교 조건으로 사용한다.
- `DNW_E = 975 keV`, `DNW_TRIM_E = 550 keV`를 이번 Triple-DNW calibration에서 고정한다.
- Main absolute dose `1.80e13 cm^-2`, Shallow absolute dose `6.00e12 cm^-2`를 유지한다.
- Deep DNW implant를 세 번째 phosphorus implant로 추가한다.
- `DNW_DEEP_E`, `DNW_DEEP_FRAC`을 SWB Parameter에 추가한다.
- PW 및 common WELL RTA는 이번 deep-tail calibration에서 고정한다.
- 후속 DOE는 Deep Energy 5수준 x Deep Dose 9수준 = 45 cases로 수행한다.
- candidate는 tail metric과 기존 core-profile metric을 동시에 평가한다.
