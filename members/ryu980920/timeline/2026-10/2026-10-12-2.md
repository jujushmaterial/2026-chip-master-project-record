## 2. 배경: DNW-only로 baseline 재현을 끝낼 수 없는 이유

[2026-10-12-1](2026-10-12-1.md)에서 81개 Triple-DNW 실험을 분석하여 **1009B Case 27 (SCORE 19.889801)**을 후보로 선정했다. DNW의 main peak, equivalent sigma는 공통 SDE surrogate baseline과 상당히 가까워졌다.

그러나 Case 27은 **PW implant를 기존 조건으로 고정**한 DNW DOE 결과였다. 실제 81개 결과의 PW 항목을 보면 여전히 다음 문제가 남아 있다.

| 항목 | SDE surrogate target | 1009B Case 27 | 남은 문제 |
|---|---:|---:|---|
| PW main peak 위치 | 109.3 nm | 100 nm (PLX grid에서 추출) | 약 9.3 nm 얕음 |
| PW peak 농도 | 5.954e17 cm^-3 | `PW_PK_R=1.422565` (약 8.470e17 cm^-3) | **약 42.3% 과다** |
| B/P active-doping crossing | 462.697 nm | 397.556 nm | 약 **65.14 nm 얕음** |
| DNW at target crossing | target ratio 1 | `P462_R=0.872985` | 약 12.7% 부족 |

`P462_R`은 **DNW PActive**의 기준 깊이 농도비이며 PW의 462 nm 농도비가 아니다. `JUNC` 역시 BActive=PActive의 **metallurgical crossover**이므로 SDevice의 SCR 위치와 같지 않다.

DNW peak/sigma가 가까워졌다고 **PW profile이나 실제 SCR까지 맞았다고 결론 내릴 수 없다.** 따라서 DNW 1009B Case 27을 일단 고정하고 PW의 shallow/main peak와 junction-side tail을 별도 DOE로 조정하기로 했다.

## 3. PW 실험에서 해결하고자 한 문제

기존 PW는 Boron dual implant 구조이다.

```text
PW_FIXED_E     = 36 keV
PW_TRIM_E      = 85 keV
PW_TOTAL_DOSE  = 2.06e13 cm^-2
PW_TRIM_FRAC   = 0.525
PW_FIXED_FRAC  = 0.475 (= 1 - PW_TRIM_FRAC, 기존 SProcess derived 값)
Common RTA    = 1050 °C / 30 s
```

이 조건에서는 near-surface PW peak가 target보다 높고, profile의 junction-side 형상이 충분히 정합됐는지 별도로 평가되지 않았다.

설계 가설:
1. Total PW dose를 고정한 상태에서 Trim Dose fraction을 증가시키면 shallow Fixed contribution을 줄이면서 더 깊은 boron contribution을 조절할 수 있다.
2. Trim Energy를 85→90→95 keV로 바꾸면 PW tail 농도의 깊이별 위치/형상이 달라질 수 있다.
3. 두 변수의 조합으로 **peak 과다를 낮추면서** 300–500 nm의 PW tail과 462.7 nm의 BActive를 더 잘 맞추는 조건이 존재하는지 검증한다.

이는 **시뮬레이션으로 검증할 가설**이지 실제 농도나 Junction이 반드시 개선된다는 뜻이 아니다. 특히 PW와 DNW의 crossing을 단독 조정해도 최종 SDevice SCR 정합이 보장되지 않는다.

## 4. PW 27개 실험조건 설계

원본 SWB 입력표: CMP2의 `CMP_SPAD_PW_Case27_27DOE_SWB.csv`.

| 독립변수 | 수준 | 의도 |
|---|---|---|
| `PW_TRIM_E` | **85 / 90 / 95 keV** (3) | PW tail의 depth 분포 민감도 |
| `PW_TRIM_FRAC` | **0.500 / 0.525 / 0.550 / 0.575 / 0.600 / 0.625 / 0.650 / 0.675 / 0.700** (9) | Fixed→Trim dose redistribution 효과 |

```text
PW DOE = 3 (Trim Energy) × 9 (Trim Fraction) = 27 conditions
PW_FIXED_E = 36 keV fixed
PW_TOTAL_DOSE = 2.06e13 cm^-2 fixed
PW_FIXED_DOSE = PW_TOTAL_DOSE × (1 - PW_TRIM_FRAC)
PW_TRIM_DOSE  = PW_TOTAL_DOSE × PW_TRIM_FRAC
```

DNW는 Case 27 그대로: Total `2.95e13`, Main E `975 keV`, Trim E `550 keV`, Deep E `1525 keV`, Trim Dose `6.50e12`, Deep Dose `7.00e12 cm^-2`. Common RTA `1050 °C/30 s`도 고정한다.

**독립변수는 두 개**이며 `PW_FIXED_FRAC`와 각 implant 절대 dose는 종속량이다. 원본 27조건표의 `index=3` (0-based)는 **기존 PW 조건 85 keV / fraction 0.525**로, Case 27의 비교 기준에 해당한다. 새 조건표를 작성했다는 사실과 실제 27개 시뮬레이션 성공을 구분한다.

고정한 SWB 값도 SWB experiment row에 기록하며, SWB에 등록된 값을 SProcess command에 상수로 치환하지 않는다. 현재 Triple-DNW Stage2 원본의 derived `PW_FIXED_FRAC`와 실제 SWB 등록 항목이 충돌하는지 여부는 원본 수정 없이 별도로 점검한다.

## 5. 왜 SVisualPy를 PW 중심으로 수정했는가?

기존 [Triple-DNW ProfileScreening v0.4](../../assets/tcad/Triple_DNW/CMP_SPAD_TripleDNW_ProfileScreening_SVisualPy_v0.4_DeepTail.md)는 DNW main peak / equivalent sigma / PActive deep tail 정합을 중심으로 설계됐다.

v0.4의 composite 가중치 구성:

```text
PW 직접 항목:  Rp 5% + Peak 4% + Shape 6% = 15%
DNW 직접 항목: Rp 8% + Peak 8% + Sigma 12% + Shape 17% = 45%
Junction/Tail joint 항목: JUNC 10% + P462 13% + Slope 12% = 35%
SPLIT: 5%
```

PW를 변경할 때 DNW 쪽 항목과 직접 관련 없는 성분이 후보 순위에 영향을 줄 수 있으므로, **DNW 지표를 버리고 PW shallow peak와 junction-side tail만 평가하는 PW-only SVisualPy**가 필요했다.

CMP2에서 만든 `CMP_SPAD_PW_ProfileScreening_SVisualPy_v1.0.py`를 원본 그대로 [PW_Propile 폴더](../../assets/tcad/PW_Propile/README.md)에 보존했다. Triple-DNW v0.4와 실제 실행 중인 SProcess v0.3 본문은 수정하지 않았다.

## 6. SVisualPy v0.4 → PW-only v1.0 변경 내역

| 구분 | Triple-DNW v0.4 | PW-only v1.0 |
|---|---|---|
| 분석 목표 | DNW core·deep tail 중심 | **PW shallow main peak·junction-side tail** |
| DNW Peak/Rp/Sigma/Tail | 추출·SCORE 반영 | **제거** |
| PActive 사용 | DNW profile 및 crossing | **crossing 계산용으로만** 유지 |
| PW Peak 탐색 | interior window 30–250 nm | 동일 main peak window 유지 |
| PW Shallow Shape | PW 종합 profile 항목 | **30–200 nm** 분리 |
| PW Tail RMSE | PW 전용 score 없음 | **300–500 nm** 별도 |
| PW Sigma | PW 전용 3분할 출력 없음 | Shallow/Tail/All 3종 |
| 462.7 nm | DNW `P462_R` | **PW `PW462_R`** |
| JUNC | PW/DNW crossing | 값 출력, **PW_SCORE 제외** |
| SCORE | PW+DNW joint | **PW-only 자체 score** |

v1.0의 PW 평가 구간은 **peak search 30–250 nm, shallow shape 30–200 nm, tail sigma 200–500 nm, tail score 300–500 nm, all sigma 0–600 nm**이다.

Sigma는 해당 window의 농도 가중 equivalent standard deviation이고 개별 Boron implant의 longitudinal straggle이 아니다. v1.0은 전체 SDE PLX 대신 **SDE에서 추출한 peak anchor + analytic Gaussian surrogate (`sigma=200 nm`)**를 형상 target으로 사용한다. 462.7 nm SDE 농도는 별도 anchor로 보존한다.

## 7. PW 전용 SCORE와 SWB 출력 10개

실제 v1.0 원본에서 사용한 SCORE 가중치:

| 항목 | 비중 | 평가 |
|---|---:|---|
| Peak 농도 | 25% | PW peak / 5.954e17 |
| Peak depth | 10% | PW Rp vs 109.3 nm |
| Shallow shape | 15% | 30–200 nm peak-normalized log RMSE |
| Junction-side Tail | 25% | 300–500 nm log RMSE |
| PW462 | 20% | 462.697 nm BActive / 1.159e17 |
| PW Split | 5% | 두 봉우리의 분리 정도 |

```text
p(e) = e / (1 + e)
PW_SCORE = 100 × (0.25 p_peak + 0.10 p_Rp + 0.15 p_shape
                + 0.25 p_tail + 0.20 p_PW462 + 0.05 p_split)
```

비율 오차는 `|log10(actual/target)|/log10(1.20)`, Rp 오차는 `|Rp-109.3|/20 nm`, RMSE는 `RMSE/0.10 dex`로 정규화하고 bounded penalty로 변환한다. 점수가 낮을수록 상대적으로 유리하지만 **DNW v0.4 SCORE나 성능 퍼센트와 직접 비교하면 안 된다.**

SWB `DOE:` 출력 10개는:

| 변수 | 의미 |
|---|---|
| `PW_SCORE` | PW-only 종합 점수 |
| `PW_SH_RP` | PW main peak depth [nm] |
| `PW_SH_PK_R` | PW peak 농도 / SDE target |
| `PW_SH_SIG` | shallow window equivalent sigma [nm] |
| `PW_TAIL_SIG` | 200–500 nm window equivalent sigma [nm] |
| `PW_TAIL_RMSE` | 300–500 nm log-RMSE [dex] |
| `PW462_R` | PW BActive at 462.7 nm / SDE concentration |
| `JUNC` | 첫 BActive=PActive crossing [nm] |
| `PW_SPLIT` | PW two-lobe separation severity |
| `PW_ALL_SIG` | 0–600 nm equivalent sigma [nm] |

`JUNC`는 PW SCORE에서 제외하며 별도 진단한다. Tail RMSE에도 462.7 nm가 포함되어 `PW462`가 그 위치에 추가 가중치를 부여하는 구조이다.

## 8. 새로 생성하도록 구현한 파일·그래프

v1.0 입력: post-RTA `n{sprocess_node}_A_R_r4p6.plx` 필수, final `n{sprocess_node}_F_r4p6.plx` 선택.

출력 접두사: `n{visual_node}_PW_v1p0`.

- `*_metrics.txt`: 상세 AR/F 지표, 각 penalty, DOE summary. Final 파일이 없다면 AR만 기록.
- `*_AR_compare.csv`: PW 전체 0–600 nm 비교곡선.
- `*_AR_shallow_plot.csv`: shallow 0–250 nm.
- `*_AR_tail_plot.csv`: junction-side tail 200–500 nm.
- `*_F_compare.csv`: optional final profile 비교곡선.
- SVisual overlay plot **2개**: PW Shallow와 PW Tail의 log concentration 비교.

BActive/PActive paired x/y PLX 변수를 지원하고, 동일 grid가 아니면 공통 depth 범위에 보간한다. Plot 생성 시 예외가 발생하면 warning을 남기며 나머지 metrics 추출을 진행하도록 작성했다. **이는 코드의 구현 내용이지 SWB에서 실제 정상 실행했다는 확인이 아니다.**

## 9. 결과 해석과 한계

1. 현재 SDE target curve는 **analytic Gaussian surrogate**이며 full SDE PLX 자체가 아니다. SDE peak와 462.7 nm anchor는 별도로 추출된 target이므로 지표 간 완전한 일치가 보장되지 않는다.
2. Tail RMSE와 Shallow Shape RMSE는 sampled grid 포인트의 단순 평균이다. 비균일 depth grid나 PLX peak-position resolution 영향은 후속 확인이 필요하다.
3. `PW_SH_SIG`, `PW_TAIL_SIG`, `PW_ALL_SIG`는 구간을 잘라 계산한 지표다. 독립 PW implant straggle 또는 절대 공정 Sigma로 해석하지 않는다.
4. `JUNC`는 도핑 crossover이지 공간전하영역 SCR이 아니다.
5. DNW 27조건 결과로 새 후보가 선정되면 PW에서 고정했던 DNW와 달라질 수 있으므로 결합 후 final profile 및 전기적 특성을 다시 검증한다.
6. v1.0 원본은 수정하지 않는다. 향후 refinement는 버전을 올린다.
