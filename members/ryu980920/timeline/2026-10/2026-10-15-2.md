## 3. 기존 PW SVisualPy v1.0의 평가상 문제

기존 v1.0은 SDE에서 추출한 몇 가지 anchor와 **analytic Gaussian surrogate**를 사용했고, SCORE에는 다음처럼 가중치를 두었다.

| v1.0 SCORE 구성 | 비중 |
|---|---:|
| Main Peak 농도 | 25% |
| Peak 위치 | 10% |
| Shallow shape (30~200 nm) | 15% |
| Deep-side Tail (300~500 nm) | 25% |
| BActive 462.7 nm 농도 | 20% |
| Split penalty | **5%** |

**문제:** 중간 **200~300 nm 구간**에서 생기는 두 번째 봉우리와 Valley 재상승을 충분히 벌점화하지 못했다. 예를 들어 기존 v1.0 SCORE 최저였던 PW Case 25는 95 keV / Trim fraction 0.650에서 Main Peak 위치 및 농도는 목표에 가까웠지만, 270 nm 부근 **두 번째 Peak가 형성**되었다.

## 4. SVisualPy 평가 체계 재설계 → 최종 v1.2.1

### 4.1 개선 과정과 버전 선택

- **v1.0:** analytic Gaussian reference 및 Split 5% 가중치. 원본을 변경하지 않고 보존.
- **v1.1 계열:** 실제 SDE 원본 비교와 split/rebound 지표를 추가하는 실험적 수정. SWB에서 코드 실행 오류가 있어 최종판으로 채택하지 않음.
- **v1.2:** SDE 원본 PLX의 샘플값을 내부에 포함하고, Shallow/Shoulder/Deep Tail 및 깊이별 농도비, Peak, Split, 종합 SCORE를 재설계.
- **v1.2.1 CompactDOE:** **v1.2의 SCORE 산식·Split 판정·상세 TXT/CSV 출력을 유지하면서 SWB DOE 표의 출력 변수만 8개로 간소화한 최종 실행본.** 해당 버전을 이번 GitHub에 보관.

코드는 SDE baseline의 실제 **BActive/PActive 수치 샘플을 자체 포함**한다. 이는 외부 PLX 경로에 의존하지 않도록 하는 구현이며, **Gaussian fit으로 기준 프로파일을 대체한 것이 아니다.**

### 4.2 v1.2.1 SCORE 구성 [surrogate scoring assumption]

| 정합 항목 | 평가 구간 또는 기준 | 가중치 |
|---|---|---:|
| Main Peak 위치 | SDE shallow peak 약 109.3 nm | **10%** |
| Main Peak 농도 | SDE shallow BActive peak 농도 | **10%** |
| Shallow-side shape | **30~110 nm** | **10%** |
| Post-peak Shoulder shape | **110~350 nm** | **20%** |
| Junction-side Tail shape | **350~600 nm** | **25%** |
| 기준 깊이 Boron 농도 | **462.6966588 nm** | **15%** |
| Split 재상승 | Main 대비 Valley→Second Peak 증가 | **10%** |
| **합계** | Peak-normalized log-shape error + bounded penalty | **100%** |

- SCORE는 **0이 이상적인, 낮을수록 우수한 정규화 mismatch 점수**다. **100−SCORE를 재현율이나 농도 정합 퍼센트로 해석하지 않는다.**
- Split은 160~350 nm 영역에서 확인한다. Valley 이후 두 번째 Peak까지 상승량을 첫 번째 Main Peak 농도로 나눈 **REBOUND_R**을 사용한다.
- **SPLIT_OK=1 조건은 REBOUND_R ≤ 0.05 (5%)**이다. 이는 실측 또는 문헌 확정 기준이 아닌 [surrogate assumption].
- **ALL_OK=1**은 Peak 위치·농도, B462 ratio(임시 0.70~1.30) 및 Split 등 코드의 잠정 관문을 통과한 경우다. SCORE 최저와 별도 판정한다.
- BActive=PActive의 **metallurgical crossing**은 진단 TXT에서 확인하며 PW SCORE에 직접 넣지 않는다. crossing은 **SDevice SCR가 아니다.**

### 4.3 SWB에는 8개 핵심 변수만 출력

| 변수명 | 의미 | 좋은 방향 |
|---|---|---|
| **PW12_SCORE** | PW weighted profile mismatch | **낮을수록 좋음** |
| **PW12_MAIN_NM** | Shallow Main Peak 깊이 [nm] | SDE 약 109.3 nm |
| **PW12_MAIN_R** | Main Peak 농도 / SDE | **1 근접** |
| **PW12_B462_R** | 462.7 nm BActive / SDE | **1 근접** |
| **PW12_REBOUND_R** | Valley→Second Peak 재상승 / Main Peak | **낮을수록 좋음** |
| **PW12_SPLIT_OK** | 재상승률 5% 이하 통과 | **1** |
| **PW12_ALL_OK** | 잠정 종합 제약 통과 | **1** |
| **PW12_RUN_OK** | 분석 정상 종료 | **1** |

Shallow/Shoulder/Tail 오차와 상세 깊이별 농도비는 **SCORE 계산에는 그대로 포함**되고, 별도 TXT/CSV에 보존된다. SWB 변수 테이블을 읽기 쉽게 하기 위해 외부 출력만 줄였다.

### 5.2 관측 결과에서 가능한 결론

1. **Trim Energy/Dose fraction 증가로 Main Peak 과다가 줄어드는 조건이 있다.** 예를 들어 95 keV / fraction 0.700의 Main Peak는 **110 nm, 농도비 0.97744**여서 SDE 기준에 가깝다.
2. 그러나 462.7 nm의 BActive ratio는 관측 최대조차 **0.36034(36.0%)**여서 심각하게 부족하다.
3. Junction-side Tail 농도를 개선하려는 조건에서는 **160~350 nm Split 재상승이 커지는 trade-off**가 관측됐다.
4. SCORE 최저 **85/0.575**도 Peak 농도비 **1.32177**, B462 **0.15723**으로 잠정 합격조건을 만족하지 않는다.
5. 따라서 **이 DOE 범위·고정 Total Dose 안에서는 Main Peak / Tail / Split 동시 정합 조건을 발견하지 못했다.** 이는 모든 Dual-PW 조합이 불가능하다는 증명은 아니다.

## 6. 후속 전략: Triple-PW의 역할 분리

이번 분석을 토대로 **PW를 Shallow Fixed + Mid + Deep의 세 Implant로 확장하는 방향을 검토**하기로 했다. 역할을 다음처럼 분리한다.

| 예정 성분 | 설계 역할 | 고려사항 |
|---|---|---|
| **Fixed (Shallow)** | 기존 약 109 nm Main Peak 형성 | **Energy 36 keV 유지**, 절대 Dose 고정 후보 도입 |
| **Deep** | 약 462.7 nm junction-side BActive 확보 | Energy를 **95 keV보다 높게**, Dose를 별도로 확대해 형상 관측 |
| **Mid (추후 추가)** | Deep 변경 후 SDE보다 **실제로 부족한 깊이 구간**을 보완 | Valley를 무조건 채우지 않음; 농도 과다/새 Peak 방지 |

특히 **Fixed 36 keV의 절대 Dose = 6.18×10¹² cm⁻²**를 이번 초기 기준으로 선택했다. 근거는 기존 95 keV / fraction 0.700 조건에서 **Main Peak 위치 110 nm, Peak ratio 0.97744**로 가장 가까웠으며, 이때 기존 Total 2.06×10¹³에서 Fixed fraction 0.300이므로 **Fixed Dose 6.18×10¹²**였기 때문이다.

**주의:** 0.97744는 Fixed 단독 Peak가 아니라 Fixed+Trim 전체의 결과다. Deep Energy/Dose를 바꾸고 Mid를 추가하면 Main Peak 높이와 위치가 다시 바뀔 수 있으므로 **6.18×10¹²는 1차 surrogate 후보**이지 최적값으로 확정하지 않는다.

## 7. 먼저 Deep PW 9조건 설계 (이번에는 여전히 Dual-PW)

Mid Implant까지 동시에 변화시키면 변수 효과가 섞이기 때문에, **Deep Energy와 절대 Dose만 먼저 탐색**한다. 36 keV Fixed는 고정하고, 기존 SProcess의 **PW_TRIM_E를 이번 Deep Energy 변수로 사용**한다. 따라서 **이번 9조건은 PW Implant 두 개**이며, 실제 Triple-PW 세 번째 주입은 아직 구현하지 않았다.

### 7.1 3×3 Deep-only 예비 DOE [surrogate DOE assumption]

| DOE 변수 | 3수준 |
|---|---|
| **PW Deep Energy (기존 PW_TRIM_E)** | **105 / 120 / 135 keV** |
| **PW Deep Dose** | **1.6 / 2.0 / 2.4×10¹³ cm⁻²** |
| **PW Fixed Energy / 절대 Dose** | **36 keV / 6.18×10¹² cm⁻² 고정** |
| **DNW** | **새 Case 15: Main 955 / Trim 550 / Deep 1485 keV** |
| **Common WELL RTA** | **1050°C / 30 s** |

Mid는 이번 9조건에서 추가하지 않는다. Deep 단독 변화 후 PLX를 확인하여 **실제로 농도가 부족해진 구간**과 과다 Peak의 이동을 판단한 다음 Mid의 Energy/Dose 탐색 범위를 설계한다.

### 7.2 고정 Dose를 유지하기 위한 DOE 행별 재계산

이번에는 **Total PW Dose를 고정하지 않고 증가 가능하게** 했다.

PW_TOTAL_DOSE = 6.18×10¹² + PW_DEEP_DOSE

PW_TRIM_FRAC = PW_DEEP_DOSE / PW_TOTAL_DOSE

PW_FIXED_FRAC = 6.18×10¹² / PW_TOTAL_DOSE

| Deep Dose [cm⁻²] | PW_TOTAL_DOSE [cm⁻²] | PW_TRIM_FRAC | PW_FIXED_FRAC |
|---:|---:|---:|---:|
| **1.6×10¹³** | **2.218×10¹³** | **0.721370604148** | **0.278629395852** |
| **2.0×10¹³** | **2.618×10¹³** | **0.763941940413** | **0.236058059587** |
| **2.4×10¹³** | **3.018×10¹³** | **0.795228628231** | **0.204771371769** |

총 **3 Energy × 3 Dose = 9조건** 입력 CSV는 로컬에서 생성했으며, **실행 결과가 확보된 것은 아니다.**

### 7.3 SWB/SProcess 연결 점검 사항

- 기존 SProcess의 DNW Main/Trim/Deep + PW Fixed/Trim + PW_SUB + **공통 Anneal 1회** 구조는 이번 9조건에서 유지한다.
- SWB에 등록된 기존 Parameter는 현재 sweep 여부와 관계없이 **@PARAMETER@**로 연결해야 한다. 고정 상수로 덮어쓰면 안 된다.
- 현재 GitHub에 보존된 Stage 2 v0.3은 **PW_FIXED_FRAC를 1−PW_TRIM_FRAC로 계산하는 derived 방식**이다. 사용자의 실제 SWB에는 PW_FIXED_FRAC가 Parameter로 등록되어 있으므로, **향후 SProcess Command를 수정·검증할 때 @PW_FIXED_FRAC@ 직접 연결과 fraction 합계 검증이 필요**하다.
- 이번 GitHub 승인 범위에는 **SProcess 코드 수정이 포함되지 않으므로**, 기존 Stage 2를 **변경하지 않았다**. 9조건에서는 CSV 각 행에서 두 Fraction의 합을 1로 맞추어 기존 derived 계산상 Fixed 절대 Dose가 유지되도록 설계했다.
- 9조건 입력 CSV, 새로운 원본 PLX 또는 SDevice 결과는 이번 승인 범위에서 **GitHub DATA 신규 업로드 제외**.
